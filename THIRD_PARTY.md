# Источники

| Ресурс                                                      | Версия / происхождение                                                                  | Условия                                                                                       |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| [Rough.js](https://github.com/rough-stuff/rough)            | 4.6.6, контуры и штриховка                                                              | MIT, лицензия в установленном пакете.                                                         |
| [GSAP](https://gsap.com/docs/v3/GSAP/gsap.utils/)           | 3.15.0, интерполяция                                                                    | Standard GSAP License, лицензия в установленном пакете.                                       |
| [Shantell Sans](https://github.com/arrowtype/shantell-sans) | Локальный WOFF2 из visual-explainer                                                     | SIL OFL 1.1: [текст](src/assets/shantell-OFL.txt), включён в поставку.                        |
| Sketch Pencil WOFF2                                         | Авторский шрифт из `visual-explainer/assets/pencil.woff2`, построен из `pencil-font.js` | Основной почерк интерфейса и источник метрик; Shantell используется для отсутствующих знаков. |
| Маркер и палитра                                            | `visual-explainer/assets/ink-marks.js`, `ink.css`, `range.css`                          | Перенесены в общие владельцы `src/ink` и `src/style.css`.                                     |
| Однолинейные буквы                                          | Авторские штрихи из visual-explainer, `pencil-font.js`                                  | Перенесены в `src/ink/glyphs.ts`, дополнены и оформлены как плотные чернила.                  |
| Рассказы о площади и остатке                                | Принятые пользователем реплики, голос и метки из `consistent-gallery/{area,remainder}`  | Используется голос без музыки; WAV перекодирован в AAC без изменения временной шкалы.         |

Зависимости разработки закреплены в `package-lock.json`. Пакет помечен `private`; публичная публикация в этой версии не выполняется.

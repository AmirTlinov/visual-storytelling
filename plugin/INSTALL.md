# Установка Visual Storytelling

Комплект для macOS 13+ на Apple Silicon содержит Node/npm, библиотеку, навык, локальный MCP и пять интерактивных примеров. Для первого просмотра дополнительные загрузки не нужны.

1. Распакуйте архив в постоянную папку. Рядом с этим файлом находятся скрытые каталоги `.agents` и `.plugin-release`.
2. В терминале из этой папки выполните:

   ```sh
   codex plugin marketplace add .
   codex plugin add visual-storytelling@visual-storytelling-local
   ```

3. Откройте Visual Storytelling в разделе плагинов Codex или попросите в чате: «Открой пример Visual Storytelling». Для нового материала: «Создай объяснение …».

Нужен доступный в терминале Codex CLI (`codex`). Разработческие Node, Python и Xcode для этого архива не нужны.

Проекты по умолчанию сохраняются в `~/Library/Application Support/Visual Storytelling/projects`. Папку новых работ можно выбрать в настройках плагина. Удаление плагина сохраняет исходники и выпуски. Для переноса работы используйте выпуск «Редактируемый проект».

Первое создание устанавливает закреплённые зависимости через npm registry. Первое видео отдельно загружает Chromium и FFmpeg с проверкой SHA-256. Голос выбирается из установленных голосов macOS; без голоса доступен весь авторский путь. Подготовку можно отменить и продолжить.

Для обновления закройте открытые представления, распакуйте новый комплект в ту же папку и выполните `codex plugin add visual-storytelling@visual-storytelling-local`. Затем переподключите плагин в Codex. Проекты сохраняют свою версию библиотеки; «Обнови библиотеку этого проекта» запускает отдельное отменяемое обновление.

Проверка нативных поверхностей Codex и установки на другом компьютере описана в `.plugin-release/docs/codex-plugin-tdd.md`. Ошибки: https://github.com/AmirTlinov/visual-storytelling/issues. Прикладывайте шаги и версию; приватные исходники и логи автоматически не отправляются.

# Аудит авторства

Карта владельцев — [архитектура](architecture.md), публичные правила —
[контракт автора](authoring.md). Этот документ связывает повторную ручную работу
с действующим общим решением. Подробные изменения сохраняются в Git.

## Что переиспользовать

| Задача                                           | Владелец и готовая основа                                                            |
| ------------------------------------------------ | ------------------------------------------------------------------------------------ |
| Персонажи, одежда, контакты, мебель, перспектива | `CharacterStory`: `perform`, `arrange`, `routines`; `characters build cast.json`     |
| Речь, постановка и тетрадь                       | `IllustratedStory`; `tesla-circuit`, `area-notebook`, `thermostat-story`             |
| Собственные главы и паузы между ними             | `SceneStory`; `Storybook` добавляет книгу и персонажей                               |
| Число → преобразование → адрес результата        | `MathMorph3D.delivery`; `result-delivery`                                            |
| Сумма или dot из 32–64 входов                    | `MathMorph` ведёт порции и накопитель; `long-calculation`                            |
| Повторно используемый SVG в объёме               | `SvgArtwork3D`; `svg-artwork`                                                        |
| Рисующийся штрих и движущийся по нему сигнал     | `InkStroke3D.draw/pointAt`; один путь и одна длина                                   |
| Стрелки между карточками и обход подписей        | `InkConnection3D`, `SvgLayout.connect`; [связи](connections.md), `connected-diagram` |
| Обновление, съёмка и выпуск                      | `update`, `review`, `export --cue`, `deliver`; общий `SceneHandle`                   |
| Движение длиннее произнесённого слова            | `cue.timing: {duration, delay?}` или `{until, delay?}`; один `Frame`                 |
| Подпись в локальной точке объекта                | `view.label(text, {object, position}, options)`; видимость, камера и очистка общие  |

Глава сохраняет последнюю позу до начала следующей; пауза речи не растягивает
выполненное действие. `SceneStory` разделяет время показа и локальное время
постановки. При своём монтаже нужно сохранить это же различие.

## Исправленные причины ручной работы

| Наблюдавшаяся проблема                                                        | Действующий путь                                                                                                                          |
| ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Замена `root.scene`, замороженные getters, потерянные class methods           | `mountScene` сохраняет один handle и обращается к живому владельцу; capabilities перечитываются                                           |
| Два времени при экспорте, угадывание ползунка, play у статичной модели        | Команды идут через handle; секунды, шаги и параметры разделены                                                                            |
| Ввод оставлял ошибочное поле; пересборка теряла исследование                  | UI/control восстанавливают значения; режим и cue восстанавливаются до повторной проверки параметров                                       |
| Ручной цикл физики с 120 Hz                                                   | `PhysicsReplay` владеет частотой, контрольными состояниями и перемоткой                                                                   |
| Собственные контролы времени книги                                            | `book/` владеет документом и timing; `NotebookPresentation` принимает часы фильма                                                         |
| Копии SVG историков и каскадные замены hex-цветов                             | Общий resolver вариаций; `characterArtwork` строит pack и sheet, включая одежду и спину; атлас допускает несколько страниц                |
| Ручная подгонка take/put под рост, книгу и стол                               | Измеренный риг и `transferApproach`; подход с достижимой видимой стороны опоры                                                            |
| Прибор менялся до касания руки                                                | `on: {press: id}` запускает реакцию от подготовленного контакта, включая reduced motion и retiming                                        |
| `Unknown prop: stimulator` для живого SVG на физическом приборе               | `propFrame` ведёт физические и плоские `art.paint/props.values`; дублирующий `activeSvg` удалён                                           |
| Удалённый стул оставлял метку `reader`                                        | `arrange` удаляет унаследованные зависимости; явно неверные ссылки отклоняются, перенесённые предметы сохраняются                         |
| Камера повторяла шаги и дыхание героя                                         | `shotFraming` измеряет диапазон поз плана относительно опоры; диагностика проверяет фактические границы                                   |
| Автоматический стол книги перекрывал прибор                                   | `book/placement` использует подходящую свободную опору или ищет место по проекции декораций; отсутствие места сообщает при подготовке     |
| Швы перспективного SVG только в захвате                                       | `paintPlane`: affine draw либо обратное перспективное отображение с premultiplied bilinear sampling; треугольный renderer удалён          |
| Обычное масштабирование разрушало размер SVG; дальние детали выступали вперёд | Внутренняя нормализация `SvgArtwork3D`, единичный публичный root и общий центр сортировки копланарных частей                              |
| Ручные смещения/масштаб `1.4`, двойной результат и остатки после seek         | `MathMorph3D.delivery` использует реальную геометрию получателя и метки расчёта/передачи                                                  |
| Невидимые предметы перехватывали клик; выбор украшал рисунок рамкой и тенью   | Общая видимость геометрии; логическая часть уточняет своего владельца; оформление только для `:focus-visible`, выбор остаётся данными     |
| Прозрачная подпись меняла раскладку и камеру                                  | `projectedLabels.measure` исключает opacity=0 из размещения, измерения и shot anchors                                                     |
| Ручные маршруты стрелок для телефона, отдельные линия/наконечник/CurvePath    | `layout/connection` измеряет препятствия; `InkConnection3D` использует один `InkStroke3D` для пути, длины и направления, включая feedback |
| Большое число тел замедляло даже небольшой видимый расчёт                     | `viewport/morph` отсекает материалы вне луча по консервативным границам того же поля и контакта                                           |
| Первый кадр нового числа задерживался на десятки миллисекунд                  | `fusion/text` один раз измеряет глиф через GSAP; повторные нативные SVG point queries удалены                                          |
| Восемь снимков главы пропускали короткие действия                             | `motion/scene-checkpoints` добавляет середину действий и обе стороны смены главы к выбранному диапазону                                |
| Подробности каждого объекта многократно повторяли данные камеры              | Камера и receipt сохраняются один раз на view; общий `queryEvidence` восстанавливает их при выборе                                    |
| Все главы заранее занимали GPU; экспорт угадывал готовность через RAF        | `composition-presentations` готовит ограниченный набор глав; Story владеет отменой и `ready`, команды и экспорт ожидают его             |
| Полный object evidence вставлялся в HTML длинного фильма                     | `motion/report-evidence` загружает выбранное окно с ограниченным кешем; CLI и HTML используют общий `queryEvidence`                   |
| Прерванный повторный захват смешивал старые времена и новые PNG              | `captureWriter` ведёт поколение и recoverable journal; manifest публикуется атомарно по кадрам, `saveCapture` использует того же владельца |
| HTTP-превью производного отчёта теряло внешние кадры и звук                  | `motion/preview` разрешает записанные media references через общий сервер, сохраняя доступ только к отчёту и его медиа                    |
| 32 входа приходилось делить вручную на четыре dot и отдельную сумму           | `arithmetic` строит ограниченные видимые стадии до 64 входов; одна метка ведёт весь расчёт, IDs и порядок вычисления сохраняются          |
| Разные списки файлов у build/watch/delivery и скрытый мусор в архиве          | Общий `sceneInput` и фактический npm packlist; README/notices учитываются, служебные файлы исключены                                      |
| Чужой runtime CLI подмешивался в сцену                                        | Генераторы, документ речи, CDN и source-архив разрешают пакет потребителя                                                                 |
| Ручные pack → hash → copy → install                                           | `update DIRECTORY --from LIBRARY` использует общий `packRuntime`, сохраняет manifest и проверяет установленное содержимое                 |
| Исходный архив включал второй одинаковый runtime                              | `closeSceneDependencies` сверяет байты; устаревший pin не подменяет использованный пакет                                                  |
| Перенос папки или смена музыки портили кэш озвучки                            | Относительные пути документа и проверка байтов аудиозависимостей                                                                          |
| `--height` терялся, `export dist` отклонялся, секунды искались вручную        | Общий CLI передаёт viewport до renderer; позиционный каталог и `--cue ID --progress` используют метки сцены                               |
| Съёмка PNG делала свежий пакет modified                                       | `previews` обновляет receipt после съёмки и отклоняет изменение исходников/runtime во время неё                                           |

Сетка и рисунок используют общие координаты: клетка 5 мм, четыре клетки — 1 см².
Книга освобождает рабочий кадр. Поля на узком экране используют горизонтальную
компоновку только на развёрнутом математическом листе.

## Основания из историй фильма

Предмет аудита — «Как машина научилась учиться · 1943–2026»: 87 глав,
7742.06 с в сохранённой проверке (129 минут). После правок речи текущий timeline
составляет 7878.78 с; сохранённая проверка относится к прежней редакции.

Журналы `.codex/sessions`: root `01a0fab9-3cef-7352-b7bb-6efa6ee75547`,
origins `01a10a19-e85e-7032-961f-105ad50a4ee4`, transformer
`01a10a1f-7aa9-7bd0-bf1b-f5ccac8796d7`, film review
`01a10648-1598-7f31-b8f9-45e734186127`. В предыдущем проходе прочитаны три
root-журнала и 12 связанных агентов; повторные записи объединялись по `item.id`.

На 5 октября 2026, время UTC:

- 04:46–04:48: `Vector operations need equally sized rows of 1 to 16 numbers`
  вынудило агента делить 32 активации на четыре `slice` по восемь и вручную
  складывать частичные результаты с bias. Отсюда общий план длинного расчёта.
- 04:48–04:55 и 08:22–08:39: ручная доставка проекции, очистка MLP/attention при
  обратном seek, совмещение CNN `0.03` с адресом. Отсюда общий `delivery`.
- 05:47–05:48: сохранение `dogScale` вручную после нормализации SVG. Отсюда
  разделение авторского transform и внутренней подгонки artwork.
- 07:22: из-за `Unknown prop: stimulator` агент удалил изменение шкалы прибора.
  Отсюда единый канал живого состояния физических и плоских SVG.
- 08:16–08:20: уменьшение стола и перенос Кахаля ради видимой книги.
  Отсюда общий выбор подхода при `put`.
- 08:33–08:41: локальный `ink.js.draw()` возвращал скрытый луч. В фильме удалено
  присваивание `root.visible`; общий `InkStroke3D.draw` уже сохраняет его.
- 08:29–08:43: агент несколько раз правил пересечения стрелок и подписей в
  мобильных seq2seq/CNN. `seq2seq.js` содержал отдельные `entryVertical`,
  `exitVertical`, `feedbackVertical`, а `learning/drawing.js` копировал длину
  штриха в `CurvePath`. Отсюда общий маршрут, измерение живых подписей и одна
  длина для штриха, наконечника и сигнала.
- 08:49–08:53: `until="end"` закрывал постановку на конце речи, за 0.6 с до
  следующей главы. Локальный монтаж теперь удерживает позу до её начала;
  общий `SceneStory` уже разделяет эти границы.

Повторный проход сверил эти истории с сохранившимися адаптерами фильма:

- `story/actions.mjs` заново реализовывал progress/elapsed/through. В нормализации
  `layer_norm.action_08` занимает 1.22136 с речи и 9 с движения; старый review видел
  только речевой интервал. Теперь явное `timing` разрешает общее окно действия,
  `speech` сохраняет исходное выравнивание. Морфинг, камера, монтаж и review читают
  этот же интервал. Изменение длительности использует кэш речи.
- `TensorDrawing.label/frameAnchors` и `history/drawing.js` вручную переводили
  точки, обходили родителей, собирали рамку и удаляли подписи. Рекомендованный
  навыком callback-якорь терял владельца. Объектный локальный якорь устраняет эту
  причину; probe hide/shot/replace/reparent находится в `artifacts/label-owner-probe/`.
- `Frame.target` называл 3D-объекты, а съёмка искала лишь `data-review-id`.
  Теперь она использует общие `data-object`, учитывает все видимые представления
  одного объекта и явно сообщает об отсутствующей области. Инспектор выбирает
  каждую видимую часть; скрытая копия и промежутки между частями не перехватывают
  выбор. PNG декодируется один раз: 64 области кадра MLP, медиана 52.9 → 5.5 ms
  при одинаковых хешах (`artifacts/review-owner-probe/region-cost.json`).
- Старый отчёт фильма ссылался на сегодняшний checkout CLI. Сборка теперь
  сохраняет отпечатки своих входных файлов; review открывает только совпавшие
  исходники или скомпилированные модули закреплённого runtime. Без такого
  подтверждения ссылка на другую версию не подставляется.
- Установленный навык содержал 33 ссылки на отсутствующие примеры и команды
  полного пакета. Вход теперь начинается с фактических `examples`/`api`, профиль
  поставки указан явно. Тихая сцена создаётся общим JS-путём без Python;
  системная озвучка использует `voice.json`, выбранные слова и кэш.
- Новая установка могла подключиться к старому процессу: сравнивался только
  `kernel.mjs`, внешние tools/core игнорировались. Общий отпечаток теперь включает
  установку и её зависимости; смена версии сохраняет одного владельца сессий.
  Проверены конфликт версий и запуск новой после штатного закрытия старой.

Ранее проба подписей воспроизвела сдвиг на 17 px и отъезд camera.z 2.33 → 204.27
из-за opacity=0; невидимые подписи теперь исключаются из рамки, fade сохраняется.
Отдельный старый скачок соседа на 14.55 px при едва заметном появлении устранён
плавной силой размещения; при opacity=1 остаётся зазор 8 px, обратный seek совпадает
с прямым (`artifacts/label-fade-probe/result.json`).
32–64 пары переполняли fragment uniforms Apple GPU. Общий план показывает до
четырёх новых пар и накопитель на стадию, включая короткие расчёты; прямой seek
сразу получает все семантические IDs и верное значение видимой стороны.

## Проверка и оставшаяся работа

Проверки выбираются по владельцу: `scene-boundary`/`authoring-session` для handle
и пересборки; `composition`/`story-state`/`physics-replay` для времени;
`viewport-labels`/`ink-stroke` и браузерные кадры для рисунка;
`characters-*` для контактов и постановки; `runtime-package`/`packaging`/
`authoring-capture` для поставки. Читаемость и движение оцениваются по реальным
кадрам и взаимодействию. Ускорение производства фильма пока не измерялось.
Из установленного пакета создана и собрана тихая сцена: play/pause, обратный seek,
изменение параметра и возврат к рассказу проверены в браузере, включая узкий экран
и тёмную тему (`artifacts/installed-authoring-probe/`).

Парные пробы dot64, Apple M5 Max / ANGLE Metal; по восемь обратных seek совпали побитово:

| Причина | Измеренный результат | Артефакт под `artifacts/` |
| --- | --- | --- |
| Материалы вне луча | За 8 с: 257 → 480 кадров; p95 66.6 → 16.8 ms, CPU p95 2.9 → 2.6 ms; 86 кадров/два ракурса, средняя разница ≤0.0089/255 | `morph-performance/summary.json`, baseline `a4de944` |
| Повторное измерение SVG-глифов | Первая стадия 68.8 → 1.9 ms, max CPU 68.8 → 4.2 ms, max RAF 66.7 → 16.8 ms; 48 кадров, разница ≤0.00022/255 | `morph-cold-stage/summary.json`, baseline `8b7d725` |

`author/review-film.mjs` снимал каждую главу отдельным `review --frames 8`:
семь из восьми действий MLP не имели внутреннего кадра. Общий план покрывал
31/731 интервалов; теперь 731/731 и границы глав. Это покрытие объявленных меток:
локальные 4–9-секундные формулы фильма ещё нужно перенести в `timing`.
Повторная съёмка текущей MLP: 45 кадров, все восемь меток, HTTP-превью PNG/звука
работает; другие главы не переснимались. Общая камера сокращает object evidence
старой MLP на 34.85%. Данные — `artifacts/film-review-checkpoints/`.

Проба 87 глав воспроизвела потерю первых 71 WebGL-контекстов при прежней
подготовке всех глав. Теперь при старте живёт одна глава, при полном проходе,
обратной и быстрой перемотке — не более двух; потерь контекста нет, после dispose
ресурсов не остаётся. Данные — `artifacts/chapter-lifecycle-probe/fixed.json`.
Обратный переход к тетради после вытеснения её исходной сцены восстанавливает
побайтно тот же кадр; `book-reverse.json` хранит результат.

Закреплённый runtime существующего фильма обновляется отдельно. Для перехода на
`delivery` нужно обновить зависимость штатной командой, удалить локальный перенос
из `scenes/calculation.js` и `deliverCell/computeInto`, проверить память, QKV,
attention, CNN и обратный seek. Авторские числа, речь и постановки сохраняются.
Там же заменить местный `link` на `InkConnection3D`, удалить дублирующие
мобильные стрелки и проверить чтение слов/feedback с длинной подписью на 390 px.

Chibi пока использует подготовленные ракурсы: непрерывный художественный оборот
и фонемная артикуляция не подготовлены. Новый научный механизм требует своей
модели и рисунка. Живой физический SVG и отдельный `CharacterSurface` работают;
одновременная композиция изменяемого корпуса и отдельного Ink-вкладыша ещё требует
общего владельца поверхности и проверки перекрытий, переноса и захвата.
Оставшиеся этапы выпуска плагина — в [его дизайне](codex-plugin-tdd.md).

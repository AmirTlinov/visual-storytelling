# Владельцы

`@visual-storytelling/core` — единственный исполняемый пакет. `src/` содержит TypeScript, `examples/` — предметные исходники, `skill/` — инструкции выбора и применения; `dist/` и `site/` пересобираются. Установленный навык ссылается на эти же файлы.

| Область                      | Владелец                                                                                                                      |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Палитра, почерк, сетка, поля | `src/styles/`, `src/assets/`, `src/ink/`                                                                                      |
| Контуры, заливки, письмо     | `SketchInk`, `SketchMotion`; Rough.js строит геометрию, GSAP интерполирует позы                                               |
| Слияние чернил              | `InkFusion` в `src/ink/fusion/`: штрихи и маски, автоматическое сопоставление с результатом, локальные контактные перемычки                    |
| Измерение и размещение SVG   | `SvgLayout`; `composition` перестраивает поверхность при изменении ширины                                                     |
| Часы                         | `story/clock.ts` читает медиавремя; `transport` владеет пуском, паузой и звуком; `SilentMedia` задаёт тихое время             |
| Плеер                        | `PlayerControls` владеет разметкой и иконками; `player` связывает медиатранспорт и подписи, `StepPlayer` и `SmilPlayer` адаптируют дискретные шаги и SVG-время |
| Рассказ и ручной ввод        | `SceneShell.attachStory` связывает `Story`, поля, главы и единый `root.scene`; `notebook.attach` возвращает этот же handle, вся очистка регистрируется у оболочки                                                  |
| Параметры и история          | `SketchControls`, `SceneHistory`; предметные ограничения остаются в сцене                                                     |
| 3D                           | `Viewport3D` владеет ракурсом, проекцией подписей, темой и ресурсами; `SvgOrbit` переносит общие OrbitControls на SVG-проекции; Three.js подключён через `./three`          |
| Сценарный ракурс              | `ViewportSVG` использует `SvgCamera` и `SvgGestures`; 3D-ракурс — `viewport/shots.ts`; оба получают ход перехода из рассказа |
| Вложенный SVG                | `ExplorerSurface`, `SvgCamera`, `SvgHighlight`, `SvgGestures`, `ScenePath` в `src/explorer/`; предметное дерево задаёт сцена  |
| Живая симуляция              | `SimulationPlayer` использует `PlayerControls`; предметная модель владеет шагом, данными и повтором                           |
| Физические объекты           | `src/physics/`: Rapier считает контакт и деформацию; привязки обновляют общий `pen` и существующие Mesh; `PhysicsPlayer` использует часы `SimulationPlayer` |
| Состояние виджета            | `widgetState` связывает хост и локальную страницу; сцена проверяет схему снимка                                               |
| Сборка и ресурсы              | `build-pages.mjs` собирает галерею и отдельные сцены, `generate-scene.mjs` запускает предметный генератор из `scene.json` прямо в выходной каталог; `assets.mjs` задаёт типы ресурсов для сборки, сервера и упаковки       |
| Доставка и съёмка             | `standalone.mjs` упаковывает HTML; `open-scene.mjs` готовит и перематывает сцену для экспорта, превью, отчётов и замеров       |
| Озвучка                      | `tools/audio/`; закреплённый Higgs TTS 3, акустические метки, монтаж и кэш                                                    |
| Разбор повествования         | `story/cues.ts` хранит действия, остановки и обращения к меткам; `tools/review.mjs` снимает переходы через общий `render.mjs` |

Рассказ рассчитывает состояние для произвольного времени, включая обратную перемотку; изменение предметных данных останавливает его, ручной ракурс сохраняет ход времени. Изменяемая симуляция продвигается шагами и повторяется из начального состояния модели. Поза и подписи обновляются вместе. WebGL рисует по изменению, часы прекращают RAF на паузе; при удалении поверхности освобождаются её обработчики и ресурсы.

Общие исправления делаются у владельца и доходят до всех примеров через сборку. Новый самостоятельный runtime, копии CSS, glyphs, плееров и vendor-библиотек в сцене не нужны. Самодостаточные SVG/HTML содержат сгенерированный код пакета и пересобираются из исходников.

Пакет собирает `tsc`, страницы — esbuild; `dev.mjs` использует ту же сборку для галереи и отдельных сцен, публикуя только законченную ревизию. Новая сцена получает версионированный tarball пакета и lockfile, чтобы обновление библиотеки было явным. Предметные генераторы LC, BERT и геометрии остаются рядом со своими сценами; производные SVG живут только в сборке. npm-пакет поставляет исполнение и CLI, авторский репозиторий — навык, каталог и референсы.

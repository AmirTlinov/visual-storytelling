# Владельцы

`@visual-storytelling/core` — единственный исполняемый пакет. `src/` содержит TypeScript, `examples/` — предметные исходники, `skill/` — инструкции выбора и применения; `dist/` и `site/` пересобираются. Установленный навык ссылается на эти же файлы.

| Область                      | Владелец                                                                                                                                                                                                                                                                                                                                                    |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Палитра, почерк, сетка, поля | `src/styles/`, `src/assets/`, `src/ink/`                                                                                                                                                                                                                                                                                                                    |
| Контуры, заливки, письмо     | `SketchInk`, `SketchMotion`; Rough.js ведёт авторские пути, `pen.contour` сохраняет измеряемые границы, GSAP интерполирует позы                                                                                                                                                                                                                             |
| Слияние чернил               | `InkFusion` в `src/ink/fusion/`: штрихи и маски, автоматическое сопоставление с результатом, локальные контактные перемычки                                                                                                                                                                                                                                 |
| Согласованный морфинг        | `src/morph/objects.ts` задаёт операции и размещение; `material.ts` — отклик на контакт и нагрузку, `timing.ts` — время рассказа; `ink.ts` — общие надписи и сетку, `body-2d.ts` / `body-3d.ts` — представления; `InkMorph` задаёт адаптивную траекторию для `Physics2D.fusion`                                                                              |
| Размер содержимого          | `src/layout/content.ts` согласует высоту самостоятельного текста и числовых ячеек; `src/morph/ink-layout.ts` размещает слова и маски по видимым штрихам |

Рассказ рассчитывает состояние для произвольного времени, включая обратную перемотку; изменение предметных данных останавливает его, ручной ракурс сохраняет ход времени. Изменяемая симуляция продвигается шагами и повторяется из начального состояния модели. Поза и подписи обновляются вместе. WebGL рисует по изменению, часы прекращают RAF на паузе; при удалении поверхности освобождаются её обработчики и ресурсы.

Общие исправления делаются у владельца и доходят до всех примеров через сборку. Новый самостоятельный runtime, копии CSS, glyphs, плееров и vendor-библиотек в сцене не нужны. Самодостаточные SVG/HTML содержат сгенерированный код пакета и пересобираются из исходников.

Пакет собирает `tsc`, страницы — esbuild; `build-output.mjs` публикует готовый результат и сохраняет предыдущий при ошибке сборки. `dev.mjs` вызывает эти же сборщики. Новая сцена получает версионированный tarball пакета и lockfile, чтобы обновление библиотеки было явным. Предметные генераторы LC, BERT и геометрии остаются рядом со своими сценами; производные SVG живут только в сборке. npm-пакет поставляет исполнение и CLI, авторский репозиторий — навык, каталог и референсы.

# Архитектура

Один пакет TypeScript/ESM. Модули сгруппированы по владельцам поведения; отдельные входы позволяют импортировать нужную область. Примеры используют публичный вход пакета, сборка галереи направляет его на тот же исходник.

**Состояние.** `stateAt(frame)` возвращает полное предметное состояние. `render` отображает его. Ручной ввод вызывает `explore(next)`, ставит рассказ на паузу и сохраняет введённые значения. `resume()` восстанавливает состояние времени рассказа; `seek()` также возвращает режим рассказа. Побочные эффекты из callback таймлайна не участвуют в вычислении модели.

**Время.** Для озвучки `transport` читает `audio.currentTime`; для тихой сцены — монотонные часы. Один RAF обновляет подписчиков только при проигрывании. Запрос запуска аудио можно отменить до разрешения `play()`. При паузе и удалении цикл прекращается. `story` согласует часы, модель и режим; общий плеер отправляет команды владельцу времени.

**Движение.** `frame.progress` выражает ход действия; `frame.reveal` позволяет мгновенно показывать рисуемую деталь при reduced motion. Момент получения значения определяется окончанием передачи. GSAP вычисляет интерполяцию, не запускает отдельный таймлайн сцены.

**Рисунок.** Rough.js владеет геометрией контура. Материалы, палитра, мягкие углы, ограничение мазков и порядок рисования принадлежат `ink`. Геометрия и длины штрихов создаются один раз. В кадре меняются преобразования, видимость, длина штриха и значения подписей. Посев зависит от устойчивого идентификатора.

**Композиция.** `object.at` размещает объект; `object.move` задаёт относительное движение. Содержимое и подписи наследуют цвет и оба преобразования. Сетка живёт в координатах SVG. `composition` перестраивает геометрию при изменении ширины и вызывает отображение текущего состояния. Шрифты загружаются перед созданием сцены.

**Доставка.** `tsc` собирает пакет и декларации типов; Vite — галерею. HTML получает встроенные ресурсы; SVG — разрешённые цвета и шрифт; PNG/MP4 используют браузерную отрисовку той же сцены. FFmpeg кодирует последовательность кадров, полученных в моменты `from + frame / fps`, и присоединяет соответствующий отрезок звука.

## Выбор зависимостей

Rough.js и GSAP уже решают используемые задачи. D3, ELK, KaTeX и Three.js подключаются в общий модуль, когда появляются реальные потребители; версия, лицензия и влияние на поставку проверяются при добавлении.

Текущее исполнение — проекция предметной модели по времени, без языка сценариев, планировщика эффектов и собственного графического движка. Перед добавлением таких возможностей нужно сравнить Motion Canvas на полном примере: голос, перемотка, параметры, темы и экспорт. Практическое сравнение Motion Canvas пока не выполнено.

# Владельцы

`@visual-storytelling/core` — единственный исполняемый пакет. `src/` содержит TypeScript, `examples/` — предметные исходники, `skill/` — инструкции выбора и применения; `dist/` и `site/` пересобираются. Установленный навык ссылается на эти же файлы.

| Область                      | Владелец                                                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Палитра, почерк, сетка, поля | `src/styles/`, `src/assets/`, `src/ink/`                                                                                       |
| Контуры, заливки, письмо     | `SketchInk`, `SketchMotion`; Rough.js строит геометрию, GSAP интерполирует позы                                                |
| Измерение и размещение SVG   | `SvgLayout`; `composition` перестраивает поверхность при изменении ширины                                                      |
| Часы                         | `story/clock.ts` читает медиавремя; `transport` владеет пуском, паузой и звуком; `SilentMedia` задаёт тихое время              |
| Плеер                        | `PlayerControls` владеет разметкой и иконками; SketchPlayer, StepPlayer, SmilPlayer адаптируют разные источники времени        |
| Рассказ и ручной ввод        | `SceneShell`; `notebook` подключает к той же оболочке типизированный `Story`                                                   |
| Параметры и история          | `SketchControls`, `SceneHistory`; предметные ограничения остаются в сцене                                                      |
| 3D                           | `Viewport3D` владеет камерой, проекцией подписей, темой и освобождением ресурсов; Three.js подключён через `./three`           |
| Читаемость и соединения      | `viewport/labels.ts`, `viewport/connections.ts`; общая геометрия границ и обхода в `layout/geometry.ts` используется также SVG |
| Объёмная математика          | `math/tensor-data.ts` хранит значения и адреса; `tensor.ts` — ячейки, `operation.ts` и `slice.ts` — смысловые переходы         |
| Сценарная камера             | `viewport/camera.ts` кадрирует объекты по меткам рассказа; ручной ракурс отделён от часов и модели                             |
| Вложенный SVG                | `ExplorerSurface`, `SvgCamera`, `SvgHighlight`, `SvgGestures`, `ScenePath` в `src/explorer/`; предметное дерево задаёт сцена   |
| Живая симуляция              | `SimulationPlayer` использует `PlayerControls`; предметная модель владеет шагом, данными и повтором                            |
| Состояние виджета            | `widgetState` связывает хост и локальную страницу; сцена проверяет схему снимка                                                |
| Сборка и ресурсы             | `build-pages.mjs` собирает галерею и отдельные сцены; `assets.mjs` задаёт типы ресурсов для сборки, сервера и упаковки         |
| Доставка и съёмка            | `standalone.mjs` упаковывает HTML; `open-scene.mjs` готовит и перематывает сцену для экспорта, превью, отчётов и замеров       |
| Озвучка                      | `tools/audio/`; закреплённый Higgs TTS 3, акустические метки, монтаж и кэш                                                     |
| Разбор повествования         | `story/cues.ts` хранит действия, остановки и обращения к меткам; `tools/review.mjs` снимает переходы через общий `render.mjs`  |

Рассказ рассчитывает состояние для произвольного времени, включая обратную перемотку; редактирование модели останавливает его, исследование ракурса сохраняет ход времени. Изменяемая симуляция продвигается шагами и повторяется из начального состояния модели. Поза и подписи обновляются вместе. WebGL рисует по изменению, часы прекращают RAF на паузе; при удалении поверхности освобождаются её обработчики и ресурсы.

Общие исправления делаются у владельца и доходят до всех примеров через сборку. Новый самостоятельный runtime, копии CSS, glyphs, плееров и vendor-библиотек в сцене не нужны. Самодостаточные SVG/HTML содержат сгенерированный код пакета и пересобираются из исходников.

Пакет собирает `tsc`, страницы — esbuild. Новая сцена получает версионированный tarball пакета и lockfile, чтобы обновление библиотеки было явным. Предметные генераторы LC, BERT и геометрии остаются рядом со своими сценами.

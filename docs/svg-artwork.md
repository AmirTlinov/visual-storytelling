# Рисунок в пространственной сцене

`SvgArtwork3D` из `@visual-storytelling/core/three` превращает SVG-пути, заливки и
обводки в геометрию. Загрузи текст один раз, затем создавай экземпляры с разными
цветами и положением. [Готовая сцена](../examples/svg-artwork/scene.js) показывает
два воздушных шара, перемотку, изменение глубины, размера и прозрачности.

```js
const art = SvgArtwork3D.create(view, source, {
  height: 3,
  colors: { '#263238': 'ink', '#d8694e': 'blue' },
});
group.add(art.root);
view.setObject(group);

// В render(values, frame): абсолютные значения воспроизводимы при перемотке.
art.root.position.set(-1, 0, values.depth);
art.root.scale.setScalar(values.size);
art.opacity(frame.reveal('appear'));
```

- `width` / `height` — положительные конечные размеры видимого рисунка в мировых
  единицах. При двух ограничениях выбирается меньший масштаб с сохранением пропорций.
- `root` изначально центрирован и имеет единичный масштаб. Размер `0.5` означает
  половину запрошенного размера; хранить и восстанавливать скрытый исходный масштаб
  не требуется. Подгонка SVG принадлежит внутреннему рисунку.
- `opacity(0…1)` обновляет пигменты и запрашивает кадр, включая паузу.
  `root.visible` и видимость отдельных слоёв остаются под управлением автора.
- `layers.get('id')` возвращает меши именованного SVG-элемента или группы в исходных
  координатах. Ими можно управлять, например скрыть свет внутри готового прибора.
- Слои одного плоского рисунка сохраняют порядок SVG при повороте камеры.
  Разные рисунки перекрываются по глубине. Камера и GPU-ресурсы принадлежат `Viewport3D`.

Рисунок остаётся плоским предметом в 3D. Текст переводи в контуры; для внешних
пояснений используй `view.label`, для объёмных предметов — геометрию или GLB.
Выразительную форму задаёт SVG, а размер, позицию, палитру и движение — экземпляр.

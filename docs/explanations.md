# Объяснение внутри кадра

Рисунок интерактива и ролик используют один кадр 16:9. `SceneShell` по умолчанию
собирает 1280 × 720: заголовок, служебная строка, предмет и предметные действия.
`SceneStory` и `IllustratedStory` наследуют этот кадр. Единственный плеер стоит
под рисунком вне его масштаба: области нажатия от 44 CSS px, текст от 16 CSS px;
на узкой поверхности элементы переносятся. Окно меняет масштаб рисунка; условия,
перемотка и выбор подробности сохраняют композицию.

Начните с `graph-lab`. Точка показывает пройденный путь; две её координаты
определяют измерение. Треугольник связывает приросты, стрелка — их отношение
со скоростью. Прогноз отмечается будущей точкой; действие продлевает тот же график.
`explorer-svg` применяет тот же язык к перемещениям: одна клетка равна одному
шагу, горизонтальное и вертикальное перемещения складываются в общий вектор.

```js
const shell = SceneShell.mount(root, { title: 'Скорость — это наклон', parameters });
const view = surface(shell.stage, {
  id: 'distance',
  title: 'Путь по времени',
  description: 'Время и путь.',
  width: shell.stage.clientWidth,
  height: shell.stage.clientHeight,
  grid: false,
});
// Подписи, формула и действия принадлежат этому рисунку.
const pointAction = svgButton(point.content, {
  x: -24,
  y: -24,
  width: 48,
  height: 48,
  label: 'Измерить наклон',
  onPress: () => shell.input({ detail: true }),
});
shell.onDispose(() => {
  pointAction.dispose();
  view.dispose();
});
```

Первым зритель замечает предмет, затем изменение, затем короткий вывод рядом
с его причиной. Числа, подписи и формулы относятся к видимой геометрии.
Длинное объяснение раскрывается последовательностью действий и глав.
Текстовые панели, раскрывающиеся вопросы и субтитры не заменяют рисунок.
Реплики доступны экранному диктору; озвучка подключается по запросу.

`shell.input(patch)` проводит действие через параметры и историю. Прогноз и
проверка входят в то же принятое условие. `Story.requested` нужен следующему
действию, `Story.presented` — описанию показанного рисунка. Переход
`shell.input({ chapter, sceneTime })` использует условия целевой главы;
`sceneTime` нормирован от 0 до 1. Результат проверки задаёт предметная модель.

| Основа              | Что менять                                                           | Общие средства                                        |
| ------------------- | -------------------------------------------------------------------- | ----------------------------------------------------- |
| `graph-lab`         | `model.js`: движение и опыт; `drawing.js`: оси; `scene.js`: действия | `plot.label`, `plot.interval`, `formula`, `svgButton` |
| `connected-diagram` | `scene.js`: последовательность; `drawing.js`: предметы и связи       | `Viewport3D`, `InkConnection3D`, семантический выбор  |
| `area-lesson`       | `story.json`: главы; `scene.js`: опыт                                | `IllustratedStory`, `areaDiagram`, `inkButton`        |

`plot.interval` получает две точки данных и вычисляет геометрию приростов и
их надписи. Для малого интервала остаётся точная геометрия; полный расчёт
показывает связанная формула. `trace.showAhead(false)` скрывает будущую линию
на время прогноза. Названия осей передаются в `xLabel`/`yLabel`, значения у точек —
в `plot.label`. После изменения модели один `plot.layout()` размещает деления,
названия, значения и измерения вместе, учитывая линии всех графиков на одном листе.
Порядок вызовов `layout()` не меняет результат. `plot.avoid(element)`
защищает расположенную рядом формулу или действие. Агент задаёт величины и связи;
зазоры и перенос подписей принадлежат графику.

```js
const value = chart.label('result', '20 м', { at: [10, 20], pigment: 'blue' });
// В render: данные, состояние и надпись обновляются вместе.
trace.at(model.time, model.distance);
value.at(model.time, model.distance);
value.text(`${model.distance} м`);
chart.layout();
```

У 2D, `SvgLayout.along` и экранных подписей `Viewport3D` один `placeLabels`:
измеренные прямоугольники, защищённые предметы, отрезки, поля и приоритеты.
`SvgLayout.viewport(space)` переводит видимую область в координаты рисунка;
её выпуклая `boundary` сохраняет настоящие края при переносе и повороте.
Одинаковые данные дают одинаковое размещение без истории кадров. `status: 'placed'`
означает свободное место с требуемым зазором; `overflow` явно обозначает нехватку
пространства. График, SVG и 3D предлагают доступное действие «Ещё подписи» только для
этого случая; `SceneHandle.presentation().layoutOverflow` сообщает их агенту.
Плотные деления сохраняют координаты, вынесенная подпись — линию к своей точке.
В 3D размещение включено по умолчанию, `labelObstacles` защищает важные предметы,
надписи на поверхностях автоматически защищены и остаются частью геометрии.
Для SVG `SvgLayout.overflow(space, { region })` подключает тот же механизм:
добавь `reserve()` в препятствия до размещения, передай неуместившиеся подписи
в `update([{ id, label, subject }])`, освободи через владельца сцены.
`SceneHandle.onDispose(cleanup)` связывает дополнительные ресурсы представления
с единственным `dispose`; HTML-оболочка SVG использует исходный handle.

Для пространственной SVG-проекции `SvgLayout.along(..., { region })` принимает
настоящий обрезанный viewport. `geometric-tensor` сохраняет подписи у осей и вектора
при повороте, масштабе и переносе через этот же владелец раскладки.

`lettering.bounds` учитывает полное перо; `pen.arrow().between(a, b)` переносит
стрелку вместе с её предметом.

Фоновая сетка принадлежит оболочке. Для измерения передайте `surface` сетку
с шагом и началом в координатах модели и задайте `paper: false` у оболочки:
камера двигает рисунок и измерительную сетку вместе, в одной области видна одна сетка.

Перо `heading` выделяет мысль, `body` подписывает предмет, `note` обозначает
вспомогательное построение. Синий связывает данные с вычислением, красный —
сравнение или прогноз. Чернила плотные; сетка и заливки спокойные.

Проверяйте реальные кадры: крайние значения, выбор клавиатурой, undo/redo,
быстрый ввод, обратную перемотку и обе темы. На узкой карточке сохраняются
16:9 и все состояния. В чате увеличение выключено: «Открыть крупнее» переводит
целый кадр в большую панель. Уже там «Читать крупнее» увеличивает рисунок;
прокрутка и клавиатура переводят внимание к деталям, Escape возвращает общий вид.
Внешнее закрытие панели сбрасывает увеличение и прокрутку без переноса фокуса.
Условия, история и геометрия сохраняются; видео и PNG выпускают полный авторский
рисунок без плеера. `presentation().frame` описывает рисунок, `viewing` — окно
чтения отдельно от его границ. Проверяйте `unreadableText` в этом режиме, а размеры
плеера — в физических CSS px на каждой поверхности. При reduced motion результат
действия остаётся видимым. MP4 всегда имеет пропорции 16:9. SVG доступен сценам,
которые предоставляют весь кадр в векторном виде.

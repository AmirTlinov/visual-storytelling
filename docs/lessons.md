# Рассказ и подробный урок

Версионируемый `StoryDocument` из `@visual-storytelling/core/story` хранит предметные
модели, представления и необязательные главы с действиями. `text` и `say` необязательны;
`say` задаёт отличающуюся реплику. Без озвучки работают
тихие метки: `seconds` или длительность чтения. `timing` растягивает действие до
следующей метки либо на заданное число секунд. Голос добавляет выровненные слова
к тому же документу; вводных пауз и переходов по умолчанию нет.
Включением голоса владеет `voice.json.enabled`; `story.json` сохраняет доступный
для озвучки сценарий и в тихом проекте. `story_voice` или `visual-story audio`
явно включают речь.

```js
import { IllustratedStory, inkChapter } from '@visual-storytelling/core/story';
import { areaDiagram } from '@visual-storytelling/core/recipes';

await IllustratedStory.mount(root, {
  document: {
    version: 1,
    models: [],
    views: [],
    title: 'Площадь прямоугольника',
    chapters: [
      {
        id: 'area',
        title: 'Считаем единичные квадраты',
        beats: [
          { id: 'count', text: 'Три квадрата в каждом из двух рядов дают шесть.', seconds: 5 },
        ],
      },
    ],
  },
  chapters: {
    area: (chapter) =>
      inkChapter({
        ...chapter,
        valuesAt: () => ({ width: 3, height: 2 }),
        create: (view) => areaDiagram(view),
      }),
  },
});
```

Добавь прогноз и опыт через управление в самом рисунке (`inkButton`, `svgButton`).
Предположение и проверка принадлежат модели сцены и проходят через `shell.input`.
Расширение прямоугольника и счёт его частей показывают результат; возврат к метке
восстанавливает исходное задание. Все главы используют общий кадр 16:9.

## Представления глав

`SceneStory` принимает `SceneChapter`; `IllustratedStory` строит эти главы из
документа через именованные фабрики. `chapter` и `sceneTime` зарезервированы общим
исследованием. Параметры `controls` и `valuesAt` задают доступные условия и их
значения в рассказе. `script` подключает готовую речевую разметку, `audio` — звук.
Команда озвучки связывает звук с `timeline.json` через `data-story-timeline` на
`audio`. `IllustratedStory` читает эту разметку; явный `script` имеет приоритет.
Без активной озвучки документ сохраняет собственное тихое время. Автономный HTML
переносит объявленную разметку вместе со звуком.

- `inkChapter` сохраняет живой SVG, сетку, доступность и команды. `create` может быть
  асинхронным. Без `size` рисунок получает доступные CSS px; в `render` перестраивай композицию под них.
  Фиксированный `size` задавай у доски в `surfaces`; интерактивная глава сохраняет адаптивные размеры.
  `create(view, signal)` и собственный `mount(parent, signal)` получают отмену:
  передай signal загрузчику и освободи частично созданные ресурсы при ошибке.
- `characterChapter` из `/characters` принимает `CharacterStageOptions` вместе с
  `id`, `title` и локальной разметкой. [Постановка](characters.md) связывает героя с живой схемой.
- `physicsChapter` из `/physics/2d` владеет `PhysicsReplay`, обратной перемоткой и
  освобождением мира. Главы с персонажами, измерениями и физическим опытом используют общий плеер.

Тетрадь и персонажная сценка занимают отдельные кадры. `characterChapter`
задаёт `presentation: 'stage'`: декорация заполняет 16:9 без тетрадного
обрамления, общие поля и выбор главы переходят под кадр. `inkChapter` задаёт
`presentation: 'explanation'` и возвращает тетрадную композицию. Своя глава
выбирает одно из этих представлений; переключение происходит при показе
подготовленного рисунка. Незавершённая подготовка сохраняет предыдущий кадр.

Собственное представление реализует `mount → render/capture/snapshot/dispose`.
`capture` фиксирует вход до первого `await`. Общий владелец готовит главы по мере
надобности и освобождает их; время, параметры, речь и экспорт остаются общими.
После прямого `seek` дождись `scene.ready()`; `scene.control` ждёт показ сам.

`documentNarration` готовит речевое задание, `documentScript` сохраняет точные
границы выровненных глав, `documentChapter` даёт локальное время речи и действия.

У beat необязательны `text` и `title`. `action` или `hold` описывает смысл для
review; эта строка сама не появляется в кадре и не озвучивается. Предметное
представление получает авторские поля через `chapter.beats`:

```js
const document = {
  version: 1,
  models: [],
  views: [],
  title: 'Остаток',
  chapters: [
    {
      id: 'groups',
      title: 'Группы',
      beats: [
        { id: 'gather', action: 'Собрать полные группы', seconds: 2 },
        { id: 'compare', hold: 'Сравнить остаток с размером группы', seconds: 3 },
        { id: 'explain', say: 'Оставшиеся предметы образуют остаток.' },
      ],
    },
  ],
};
const chapter = documentChapter(document, 'groups');
// chapter.script.cues.gather — обычное локальное время 0…2 для рисунка.
```

`say` по умолчанию берётся из `text`; `say: ''` явно оставляет шаг немым.
`seconds` задаёт его локальный интервал, `timing` — явное окно действия.
Без текста и `seconds` используется длительность `timing.duration` с задержкой
или 2,5 секунды. Немой шаг не создаёт подпись, речевой сегмент или `speech`.
В смешанном рассказе озвучиваются непрерывные группы реплик, а немые действия
занимают штатные паузы. Звук и точные метки слов сохраняются; устаревшая разметка,
в которой действие не помещается между репликами, требует повторной озвучки.
До синтеза длительность речи неизвестна, поэтому перед немым шагом резервируется
полное явное окно предшествующего действия. Этот запас может добавить тишину;
при прослушивании согласуй его с наблюдением и темпом рассказа.

Справка по выпуску и проверке — в [контракте автора](authoring.md).

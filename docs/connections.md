# Связи между фигурами

Указывай отправителя, получателя и препятствия. Маршрут измеряет фигуры, выбирает
свободные стороны и обходит их с отступом. Обновление детерминировано: возвращение
к прежней компоновке восстанавливает ту же трассу.

## Диаграмма в Three

```js
import { InkConnection3D } from '@visual-storytelling/core/three';

const link = InkConnection3D.create(view, encoder, memory, {
  space: diagram,
  avoid: [decoder, explanation],
  color: 'purple',
});

// После размещения фигур и изменения текста:
link.update();
link.draw(frame.reveal('send'));
signal.position.fromArray(link.pointAt(frame.reveal('send')));

// Следующее слово использует ту же связь:
link.update({ from: words[index] });
```

`space` — общая плоскость диаграммы, локальные X вправо и Y вверх. В неё уже
добавлен `link.root`. Поворот и масштаб всей группы сохраняют привязки.
Вложенные фигуры измеряются в её координатах. `pointAt` и `tangentAt` возвращают
локальные `[x,y,z]`; линия, наконечник и сигнал используют одну длину.
Viewport владеет GPU, временем — существующий рассказ.

Физические подписи передавай целым результатом `view.label(..., {space:'world'})`:
вызов `update` обновит их текст и размеры до прокладки пути. Экранные аннотации
относятся к компоновке viewport и не являются препятствиями плоской диаграммы.
Скрытые и полностью прозрачные фигуры исключаются. При скрытом отправителе или
получателе трасса пуста, `pointAt` возвращает `undefined`.

По умолчанию `gap: 0.08`, `clearance: 0.18`, `depth: 0.06`, `headSize: 0.16`
измеряются в единицах плоскости; толщина штриха остаётся в экранных пикселях.
`arrow:false` оставляет линию. Самосоединение обходит своё тело через разные
стороны. `fromSide` и `toSide` (`left/right/top/bottom`) закрепляют нужные порты.
Невозможная компоновка сообщает ошибку и сохраняет предыдущую трассу.

[Пример](../examples/connected-diagram/scene.js): чтение слов, память, декодер
и обратная связь; широкая и узкая компоновки, новая подпись и перемотка.

## SVG

```js
const route = SvgLayout.connect(first.shape, second.shape, {
  space: drawing.layer,
  route: 'orthogonal',
  avoid: [third.element, explanation.element],
  clearance: 8,
});
stroke.update(route.d);
SvgLayout.along(caption.element, route, {
  space: drawing.layer,
  avoid: [first.element, second.element, third.element],
});
```

`connect` возвращает `start`, `end`, `points`, `d`; `along` учитывает все изгибы.
При заданном `avoid` ортогональный маршрут выбирается автоматически. Без него
сохраняется прямая связь. SVG-адаптер измеряет конечные фигуры для подготовки
рисунка, видимость штриха задаёт его автор. Скрытые препятствия исключаются.

Оба адаптера используют `layout/connection`. Он прокладывает связи между уже
размещёнными фигурами. Расстановка фигур и смысл пересечения разных связей
остаются частью композиции сцены.

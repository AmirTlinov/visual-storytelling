# Рассказ поверх готового морфинга

`MorphStory.mount` связывает существующий рендерер с главами, параметрами и временем
`Story`. Его используют [числа и тела](../examples/morph-story/scene.js),
[самостоятельные надписи](../examples/ink-story/scene.js) и
[математические конструкции](../examples/formula-objects/scene.js).
Материал, письмо, камера и компоновка остаются у `MathMorph` / `InkMorph`.

```js
import { MorphStory, MathMorph } from '@visual-storytelling/core';
import '@visual-storytelling/core/style.css';

window.galleryReady = MorphStory.mount(document.querySelector('main'), {
  title: 'Как складываются части',
  presenter: MathMorph,
  initial: { a: 2, b: 3 },
  parameters: [{ key: 'a', label: 'Первая часть', min: 1, max: 6 }],
  script: {
    duration: 6,
    cues: { sum: { start: 1, end: 4, action: 'Две части соединяются в целое.' } },
  },
  chapters: [{ id: 'sum', operation: (p) => MathMorph.add(p.a, p.b) }],
});
```

Автор задаёт модель операции и её метки. Оболочка готовит шрифты, создаёт поля,
подключает камеру и плеер, выбирает главу, синхронизирует исследование и перемотку,
освобождает ресурсы. `root.scene` сохраняет общий контракт просмотра и экспорта.

- `initial` хранит параметры, включая массивы и тензоры. `parameters` описывает
  только редактируемые скалярные поля; их значения берутся из `initial`.
- `operation(parameters)` — чистая фабрика. Её результат кэшируется по значениям
  параметров, по одному варианту на главу. Массивы и объекты передавай неизменяемыми.
  Время, ракурс и ползунок преобразования не запускают подготовку заново.
- `chapter.cues` принимает одну метку для всей операции либо метки её стадий.
  По умолчанию используются действия `id_*`, затем собственная метка `id`.
  Заголовок и начало главы берутся из одноимённого сегмента сценария.
- `chapter.initial` задаёт параметры рассказа этой главы. `descriptions` меняет
  подписи и формат полей; сами поля сохраняют фокус и незавершённый ввод.
- `audio` подключает существующую озвучку; `captions` включает общие субтитры.
  При исследовании сохраняются длительность действия и reduced motion.
- Результат содержит `shell`, `story`, `presentation`, `dispose`. Дополнительные
  предметные действия используют эти же владельцы. Некорректный ввод сообщает
  об ошибке в оболочке и сохраняет последнее корректное состояние.

`presenter` соответствует небольшому контракту `mount`, `setOperation`, `render`,
`dispose`, необязательным `plan` и `view`. `MathMorph` и `InkMorph` подходят напрямую.
Для нестандартной смешанной сцены остаётся `SceneShell.attachStory`; новый плеер,
таймер и рендерер для рассказа не нужны.

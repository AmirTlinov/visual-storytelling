# Рассказ поверх готового морфинга

`MorphStory.mount` связывает готовое представление `MathMorph` или `InkMorph`
с главами, параметрами и временем `Story`. Оно подходит для рассказа,
в котором каждая глава целиком посвящена одной операции. Материал, письмо,
камера и компоновка остаются у представления; `operation` может возвращать
арифметическую операцию или план `MathMorph.model(...).explain(...)`.

В кадре 16:9 геометрические планы `MathMorph` компонуют рисунок по фактическому
размеру поверхности. Подписи сохраняют экранный размер; формула находится возле
рисунка, а длинный разбор на узкой поверхности открывается действием «Разбор».
В обычном HTML-контейнере тот же план остаётся документом естественной высоты.

Смешанный [GPT-эталон](../examples/gpt-model/scene.js) использует
`SceneShell.attachStory`: общая схема и [вычислительная панель](../examples/gpt-model/computation.js)
читают одну модель и одни часы. `MorphStory` не требуется для встраивания MathMorph
в существующую сцену.

```js
import { MorphStory, MathMorph } from '@visual-storytelling/core';
import '@visual-storytelling/core/style.css';

window.galleryReady = MorphStory.mount(document.querySelector('main'), {
  title: 'Как складываются части',
  presenter: MathMorph,
  initial: { a: 2, b: 3 },
  parameters: [{ key: 'a', label: 'Первая часть', min: 1, max: 6 }],
  script: {
    duration: 6,
    cues: { sum: { start: 1, end: 4, action: 'Две части соединяются в целое.' } },
  },
  chapters: [{ id: 'sum', operation: (p) => MathMorph.add(p.a, p.b) }],
});
```

Автор задаёт модель операции и её метки. Оболочка готовит шрифты, создаёт поля,
подключает камеру и единственный плеер под рисунком, выбирает главу,
синхронизирует исследование и перемотку, освобождает ресурсы.
`root.scene` сохраняет общий контракт просмотра и экспорта композиции 16:9.

- `initial` хранит параметры, включая массивы и тензоры. `parameters` описывает
  только редактируемые скалярные поля; их значения берутся из `initial`.
- `operation(parameters)` — чистая фабрика. Её результат кэшируется по значениям
  параметров, по одному варианту на главу. Массивы и объекты передавай неизменяемыми.
  Время, ракурс и ползунок преобразования не запускают подготовку заново.
- `chapter.cues` принимает одну метку для всей операции либо метки её стадий.
  По умолчанию используются действия `id_*`, затем собственная метка `id`.
  Заголовок и начало главы берутся из одноимённого сегмента сценария.
- `chapter.initial` задаёт параметры рассказа этой главы. `descriptions` меняет
  подписи, формат и `disabled` полей; сами поля сохраняют фокус и незавершённый ввод.
- `audio` подключает выбранную пользователем готовую озвучку. Пояснения
  остаются возле предметов; без `captions` текст глав доступен скринридеру.
  При исследовании сохраняются длительность действия и reduced motion.
- Результат содержит `shell`, `story`, `presentation`, `dispose`. Дополнительные
  предметные действия используют эти же владельцы. Некорректный ввод сообщает
  об ошибке в оболочке и сохраняет последний подтверждённый кадр.

`presenter` содержит `mount` и необязательный `plan`; созданное представление —
`setOperation`, `render`, `dispose` и необязательный `view`. `MathMorph` и `InkMorph`
подходят напрямую. Представление владеет освобождением своих ресурсов;
`root.scene` заимствует у его `view` фокус, ракурс и восстановление камеры.

Для смешанной сцены переиспользуй представление между предметными действиями,
передавай в `render` прогресс существующего `Story` и вызывай `dispose` вместе
со сценой. [Настройки MathMorph](morphing.md#встроенное-вычисление) позволяют
вписать короткую формулу, локальные знаки и числовые тела в общую композицию.

# Движение тензоров

`@visual-storytelling/core/three` перемещает существующие ячейки:

- `arrangeTensorRows(rows, destinations)` перемещает исходные ряды в свободные полосы, затем сближает их по горизонтали; соединение не создаёт копию результата.
- `deliverTensorCells(output, {from, start, end})` переносит сами принимающие ячейки и оставляет их в точке назначения; `from` задаётся в локальных координатах группы результата.

Создай действие один раз; в `render` передавай прогресс реплики. Все положения и видимость восстанавливаются при обратной перемотке. [Tensor3D](tensors.md) предоставляет общий `TensorHandle`: `object`, адресуемые `cells`, `reveal` и `titleLabel`. Числа принадлежат `TensorData`; вычислением и превращением операндов в результат владеет [MathMorph](morphing.md#числовые-ячейки).

```js
const deliver = deliverTensorCells(row, {
  from: row.cells.map((cell) => [cell.base.x, cell.base.y + 0.65, cell.base.z]),
});
// В render перемещаются те же ячейки; отдельная копия результата не создаётся.
deliver(frame.progress('place_cells'));
```

Оставь свободные полосы движения и зазоры между неподвижными и движущимися ячейками.

`view.shot({target: group, bounds, direction, padding})` сохраняет авторскую область движения и учитывает размеры подписей. `bounds` задаёт постоянный охват, включая будущие положения; без него камера подстраивается под видимую геометрию. `Viewport3D` применяет кадр через общий `readableFrame` и сохраняет ручное вращение до возврата по Home.

Для приближения точно к одному месту укажи `lockTarget: true`: камера сохраняет центр `bounds` как точку взгляда и увеличивает расстояние, когда геометрии или подписям нужно больше места. Общий и близкий кадры с одинаковым центром дают прямой наезд; кадры с разными центрами — перенос между ними. Если один из концов перехода фиксирован, точка взгляда плавно проходит между целями двух конечных кадров. Для прямого вызова `readableFrame` этому соответствует `lockCenter: true`.

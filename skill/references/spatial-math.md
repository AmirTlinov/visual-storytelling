# Объёмные данные и действия

Начни с [математических действий](../examples/math-workbench/scene.js) или
[извлечения среза](../examples/tensor-slices/scene.js): сцена задаёт данные и метки,
общая библиотека — геометрию, читаемость, перенос значений и камеру.

```js
import { Viewport3D, vectorOperation, cameraTrack } from '@visual-storytelling/core/three';

const view = Viewport3D.mount(shell.stage);
await view.ready;
const action = vectorOperation(view, {
  id: 'displacements',
  kind: 'add',
  a: [2, -1],
  b: [0.5, 3],
  labels: { a: 'первое смещение', b: 'второе смещение', result: 'вместе' },
});
view.setObject(action.group, { fitView: false });
const camera = cameraTrack(view, { target: action.framing, direction: [0.12, 0.08, 1] });
// В существующем render(time, cues, reduced):
action.render(cues.progress('combine', time), reduced);
camera.render(time, reduced);
```

| Задача                                                        | Общий владелец                                                                                                                                                                                                                                            |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Форма, оси и значения                                         | `TensorData(shape, values, axes)`; `at`, `slice`, `transpose`, `reshape` сохраняют логические адреса.                                                                                                                                                     |
| Скаляр, вектор, матрица, три оси                              | `TensorView(view, data, {id, title, tone})`; `layout(columns)` переносит только вектор, сохраняя оси матрицы. Для большего числа осей явно выбери срез.                                                                                                   |
| Сложение, покоординатное произведение, скалярное произведение | `vectorOperation` с `kind: 'add' / 'multiply' / 'dot'`; отдельная область вычисления и получение результата при прибытии вклада.                                                                                                                          |
| Извлечение первого измерения                                  | `tensorSlice(view, tensor, {id, index, title})`; `render(progress, reduced)` переносит копию с сохранением адресов источника. Другую ось сначала выбери через `TensorData`.                                                                               |
| Соединение объектов                                           | `view.connect(from, to, {tone})`; зарегистрированные тела и подписи обходятся автоматически, концы оставляют зазор. `view.avoid(object)` регистрирует дополнительное препятствие и возвращает очистку. В SVG используй `SvgLayout.connect(..., {avoid})`. |
| Ракурс по смыслу                                              | `cameraTrack(view, initial, [{cue, target, direction, travel}])`; камера прибывает к началу действия. `framing` сохраняет габариты композиции во время переноса.                                                                                          |

Число и ячейка имеют одну идентичность; плоские грани сохраняют свою геометрию,
тон боковых граней объясняет глубину. Полная надпись помещается в проекцию грани
либо получает выноску; закрытые другим телом числа не просвечивают сквозь него.
Размеры измеряются после загрузки шрифта. Готовые операции перестраивают колонки
и увеличивают высоту на узкой поверхности, сохраняя читаемые числа.
`formatNumber` сохраняет малые величины и отмечает округлённые значения знаком `≈`;
полные данные остаются в модели, собственный `format` задаёт предметную запись.

Ручное вращение отсоединяет камеру от сценария и сохраняет ход рассказа.
Для оболочки укажи `exploration: 'view'`; возврат вызывает `camera.resume(time)`.
Обновляй действие и камеру из одних часов. Обратная перемотка восстанавливает
те же значения; reduced motion сохраняет момент получения результата.

`view.inspect()` возвращает непрочитанные подписи и соединения без свободного пути.
Исправь ракурс, плотность или разбиение шага по этому сигналу; затем просмотри
переход глазами. Проверь обе темы, узкую ширину, ручное вращение во время рассказа
и повторную смену действия. При удалении вызови `camera.dispose()`,
`action.dispose()`, `view.dispose()` и `shell.dispose()`.

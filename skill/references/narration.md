# Озвучка, музыка и единое время

Сцены и их предметную логику автор пишет свободно в JS. `sketch-audio` отвечает
за голос, акустическое выравнивание текста, паузы и музыкальный микс.
Код инструмента находится в `scripts/`; модели, окружение и кэш — вне скилла,
в `~/.cache/sketch-visualization` (можно задать `SKETCH_AUDIO_CACHE`).

## Запуск

```sh
sketch-audio doctor
sketch-audio build narration.json --out ./audio
node scripts/scene.mjs preview ./scene/dist
```

Если команды нет в PATH, используй `scripts/sketch-audio` из этого скилла.
Для нового Mac с Apple Silicon: `scripts/sketch-audio setup`. Нужны `uv`, Python 3.12 и FFmpeg;
Python-зависимости зафиксированы в `scripts/uv.lock`. Setup один раз загружает
Higgs TTS 3 BF16 (около 9.3 GB), русский выравниватель (около 1.3 GB)
и пример музыки. Принятый мужской образец уже входит в скилл:
`dist/assets/audio/narrator-male.wav` в библиотеке; повторно создавать голос не нужно.
Генерация и выравнивание идут локально; API-ключи и голосовой режим Codex не нужны.

До синтеза свяжи реплики с действиями по
[визуальной раскадровке](visual-storytelling.md). В каждой ключевой фразе
должно быть время увидеть исходное состояние, преобразование и его результат.
Подгоняй реплику и паузы под объясняемое действие. Если при сборке обнаружился
смысловой разрыв, вернись к сцене и пересобери затронутую фразу.

Перенеси готовые реплики в формат [рабочего сценария](../examples/remainder-story/narration.json).
Входные поля:

- `version: 3`, `intro`, `outro` — секунды до/после речи.
- `voice`: `seed` (42), `delivery` (по умолчанию
  `<|emotion:enthusiasm|><|prosody:expressive_high|>`). Все фразы
  используют встроенный мужской образец. Для своего тембра задай
  `reference_audio` и его точный `reference_text`; путь считается от сценария.
- `segments`: смысловые фразы с уникальным `id`, `text`, необязательными
  `delivery`, `pause_after` и `cues`. Сегмент содержит связную законченную реплику,
  которую синтезатор произносит целиком; длинный абзац дели по смысловым действиям.
  Внутренние паузы создаёт модель,
  `pause_after` по умолчанию равен нулю. Дополнительную паузу задавай для
  конкретного действия на рисунке.
- `delivery` сегмента заменяет общую подачу; пустая строка оставляет её образцу.
  Пример: `<|emotion:amusement|><|prosody:expressive_high|>`.
  В `text` допустимы [штатные теги Higgs](https://huggingface.co/bosonai/higgs-tts-3-4b/blob/main/PROMPTING.md),
  например `<|style:whispering|>` или `<|emotion:surprise|>`.
  Они исключаются из субтитров и выравнивания. Используй тег по смыслу;
  базовая подача уже выразительная.
- Числа, формулы и латинские сокращения пиши произносимыми русскими словами;
  на рисунке остаётся любая математическая запись. Используй `ё`, где она нужна.
  Используй обычную орфографию без специальных знаков ударения.
- `cues: [{"id":"answer", "quote":"двадцать три", "action":"Под группами появляется общее количество 23"}]` создаёт именованный
  интервал по словам. Для повторяющейся цитаты добавь `occurrence: 2`.
  ID сегментов и меток составляют одно пространство имён:
  строчная латинская буква, затем строчные буквы, цифры, `_`, `.` или `-`
  (`[a-z][a-z0-9_.-]*`), например `count_tiles`.
  Каждой авторской метке дай `action` (что видно до, во время и после действия)
  либо `hold` (что зритель читает, сравнивает или предсказывает). Глагол привязывай
  к операции над предметами. Метки сегментов служат навигации по главам.
- `music: null` отключает музыку. Пример: `{"track":"inspired","offset":32,
  "level_db":-19}`. Для другой композиции: `path`, `offset`, `level_db` и
  `credit` с `title`, `artist`, `source`, `license`, при наличии `license_url`.
  Относительный путь считается от сценария. Название трека не задаёт настроение
  всем будущим роликам: выбирай музыку по конкретному материалу.

Результат: `audio.wav` (готовая общая дорожка), `voice.wav`, при музыке
`music.wav` (уже приглушённый фон), `CREDITS.txt`, `narration.txt`, `timeline.json`.
Сцена импортирует `timeline.json`; сборщик включает его в итоговый JS.
Все WAV начинаются в общей точке ноль и имеют одинаковую длительность.
Музыка тише голоса, автоматически приглушается во время речи и плавно входит/выходит.
Визуализация воспроизводит `audio.wav`; стемы оставлены для редактирования.

Повторная сборка переиспользует неизменённые голосовые фрагменты и их метки.
Правки музыки, вводной паузы и пауз между фрагментами пересчитывают монтаж
без повторного синтеза. Файлы сцены в выходном каталоге не изменяются.

Создание сцены с зависимостями и упаковка для чата описаны в
[справке сцены](scene-authoring.md).
Preview поддерживает byte-range запросы для перемотки WAV; обычный HTTP-сервер
может оставить аудио без доступной перемотки.

## Метки и JS

В `timeline.json` все `start`/`end` уже относятся к итоговой дорожке:

- `segments[]`: `id`, `text`, `start`, `end`, `audio_start`, `audio_end`,
  `words[]` с текстом, временем и акустическим `score`.
- `cues[id]`: `text`, `start`, `end`, авторские `action`/`hold` — сегменты и цитаты.
- `duration`, имена аудиофайлов, сведения о сборке, музыке и `warnings`.

Импортируй помощник пакета и метки, затем дождись шрифта:

```js
import { SketchMotion, SketchPlayer } from '@visual-storytelling/core';
import timing from './timeline.json' with {type: 'json'};
await document.fonts.ready;
const {write, draw} = SketchMotion;
const player = SketchPlayer.mount(root, {
  audio, timing,
  render(time, clock, reduced) {
    const frame = clock.at(time, reduced);
    write(answerText, frame.reveal('answer'));
    draw(underline, frame.reveal('answer'));
  }
});
// Пуск, пауза и звук подключены к общему управлению в [data-player].
// Перемотка работает в обе стороны, меняя всю сцену:
player.seekCue('answer');
root.scene = { review: player.review, dispose: player.dispose };
```

`player.dispose()` вызывается при удалении сцены и останавливает озвучку.

Каждый кадр вычисляй как `render(audio.currentTime)`: показываемые элементы,
камера, штрихи и значения должны восстанавливаться при перемотке. Таймеры,
цепочки `setTimeout` и отдельные часы анимации создают рассинхронизацию.
Для интерактивного изменения исходных данных заново собери соответствующий
сценарий или явно переключи режим; прежняя озвучка относится к своему примеру.
Выключение звука глушит всю дорожку, сохраняя ход анимации и выбор звука при повторе.

`write` рисует упорядоченные штрихи букв из `src/ink/glyphs.ts`: кириллица,
латиница, цифры и основные знаки. `writeSequence([elements], p)` пишет ряд
последовательно внутри одного смыслового действия. Для отдельно произносимых
размеров, слагаемых, знаков и ответа используй отдельные `cues` и `write`:

```js
write(heightLabel, clock.progress('height_value', time)); // «четыре сантиметра»
write(widthLabel, clock.progress('width_value', time));   // «пять сантиметров»
write(productSign, clock.progress('multiply_sign', time)); // «умножить на»
write(resultLabel, clock.progress('product_result', time)); // «двадцать»
```

Метка абзаца подходит для навигации по главам. Вывод нового факта начинается
на его словах и заканчивается к концу соответствующей реплики; паузы сохраняются.
Разбиение общей длительности по длине надписей не учитывает речь.
Действие над несколькими предметами можно распределить внутри метки своего
глагола: например, добавить три ряда за «добавим ещё три таких ряда».
`clock.at(time, reduced)` использует тот же `Frame`, что и типизированный `story`:
`progress(id)` — ход операции, `has(id)` — начало, `finished(id)` — завершение;
`reveal(id)` сокращает декоративное рисование при reduced motion. При копировании
значение получателя меняется по `finished`, даже если движение отключено:

```js
const frame = clock.at(time, reduced);
transferDrawing.render(frame.progress('copy'), reduced);
receiver.set(frame.finished('copy') ? sourceValue : previousValue);
```

Для изменяющихся величин вычисляй все зависимые числа из текущего входа.
В reduced-motion сохраняй время получения результата и порядок фактов.

`draw(path,p)` рисует отдельный штрих, `trace([paths],p)` —
несколько по очереди, например стержень и наконечник стрелки. Разделяй пути
в местах отрыва пера (`M`); кончик штриха перемещается по его геометрии.
Если нужен отсутствующий символ, добавь осевые штрихи либо оставь его статичным.
После изменения текста/переноса вызови `resetText` и пересчитай композицию.

## Речь и музыка

Higgs TTS 3 — основной локальный генератор русской речи. Сохраняй принятый
мужской тембр и естественный темп. Эмоции задаются штатными средствами модели;
ускорение и изменение высоты готовой записи в сборке отсутствуют.
Исходные параметры: BF16, `temperature: 0.8`, `top_k: 50`, `seed: 42`.
Время для рисунка обеспечивай формулировкой и смысловыми границами рассказа.
Для смены рассказчика используй чистую запись на русском и точную расшифровку.

Выбирай негромкую инструментальную музыку без конкурирующего вокала и резких
переходов; настроение следует теме. У свободного трека сохрани источник,
лицензию и атрибуцию в `CREDITS.txt`; подпись под роликом не нужна.
Пример Inspired — Kevin MacLeod,
[источник](https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1600022),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

## Проверка

После сборки сцены получи кадры на границах и внутри авторских меток:

```sh
visual-story review dist --out review
visual-story review dist --out review-narrow --cue copy --width 375 --theme dark --reduced
```

Открой `review/index.html`: реплика, задуманный переход и семь кадров от «до» до
«после», а при наличии `snapshot()` — состояние модели. `review.json` хранит время,
диагностику и состояния без изображений. `--cue` можно повторять для локальной проверки.
На `window.explainer` или `root.scene` выставь `review: player.review`; для `story` —
`review: controller.sheet.review`, для `SceneShell.attachStory` — `review: story.review`.
Читай метки через `clock.cue`, `clock.at` или `sheet.at`, чтобы учитывались обращения.

Отчёт отмечает метки без описания, непрочитанные метки и действия с одинаковыми
кадрами. `hold` допускает неподвижность. Обращение к метке само по себе не доказывает
правильность показа: сопоставь видимое действие с репликой, проверь промежуточные
равенства и происхождение результата. Отчёт дополняет полный просмотр со звуком
и проверку перемотки; смена камеры или подписи может скрывать неподвижный механизм.
Метки получены CTC-выравниванием:
это акустические оценки с шагом около 20 ms, не гарантированные фонетические
границы. Посмотри `warnings` и контрольные акценты: скопление неуверенных слов у
конца записи может означать пропуск речи, поэтому сверь её с текстом и пересобери
затронутую реплику более короткими смысловыми фрагментами.
Отсутствующую речь нельзя исправить растягиванием меток по длительности.

Бэкэнд: [Higgs TTS 3 BF16](https://huggingface.co/bosonai/higgs-tts-3-4b)
через MLX Audio на GPU Apple Silicon;
[русский Wav2Vec2](https://huggingface.co/jonatasgrosman/wav2vec2-large-xlsr-53-russian)
создаёт метки. Ревизии обеих моделей закреплены в `scripts/audio/resources.py`.
Выравниватель использует MPS, когда доступен; `--device cpu` меняет только его устройство.
`timeline.json` сохраняет модель, ревизию, версию MLX Audio и хеш образца голоса.
`CREDITS.txt` всегда содержит атрибуцию Boson AI. Лицензия Higgs допускает
бесплатные авторские ролики, в том числе монетизированные, с заметной атрибуцией
в записи или сопровождающем тексте. Встраивание модели в продукт требует
отдельной лицензии; условия находятся в карточке модели.

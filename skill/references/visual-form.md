# Образцы и готовые действия

## Последовательное объяснение

Полная серия из 21 исходного кадра о китайской теореме об остатках сохранена
в [sequence](../assets/explained-math/sequence/). Номера соответствуют порядку
вложений; [источник](../assets/explained-math/sequence/source.json) содержит
имена и контрольные суммы. Ниже четыре опорных кадра: выбери подходящий приём.
PNG сохранены без изменений. Переноси порядок объяснения; оформление выбирай под задачу.

| Шаг | Кадр | Приём |
| --- | --- | --- |
| Дать условие | [Остатки 2, 3, 2](../assets/explained-math/sequence/04.png) | Число рядом с обычной фразой. |

## Поддерживаемые примеры

Текущие сцены и их превью находятся в [таблице выбора](../SKILL.md#образцы).
Создай выбранный пример через `scene.mjs new`, затем выполни в его каталоге
`npm install`, `npm run build` и `npm run dev`; для чата используй `scene.mjs pack` по [инструкции](scene-authoring.md).
Встроенные стили, фон, подписи и управление берутся из общего набора ассетов.

[Первый образец стиля](../assets/style-reference.png) и
[перенос разряда](../assets/binary-carry.png) показывают отдельные графические приёмы;
готовую сцену начинай с текущего исходника из таблицы.

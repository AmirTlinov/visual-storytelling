# График данных как воспроизводимый источник

Числовой график рождается из данных в коде. Код владеет выборкой,
преобразованиями, соответствием величин зрительным признакам, осями,
интервалами неопределённости и легендой. Экспортированный SVG переносит этот
результат в статью, самостоятельную схему или композицию Figma.

```text
данные → код графика → SVG графика → итоговая композиция
```

Так изменение данных возвращается в код и снова порождает весь график. Место
графика, общий заголовок, поясняющие стрелки и связь с остальным повествованием
возвращаются к владельцу итоговой композиции.

## Выбор инструмента

Сохраняй подходящий инструмент проекта, если он воспроизводит нужные величины,
оси и неопределённость и экспортирует SVG. Для простого графика достаточно
имеющегося средства построения; для публикационной фигуры предпочитай
Matplotlib и SciencePlots, когда они дают нужную типографику и стиль издания.

Зависимости добавляй только для выбранного маршрута. Если график входит в
проект, используй его менеджер пакетов и файл фиксации версий. Для отдельной
иллюстрации объяви зависимости у её генератора или в окружении задачи.

## Публикационный маршрут: Matplotlib + SciencePlots

1. Назови величины, единицы, выборку, преобразование и неопределённость. Сначала
   установи, какое различие должен увидеть читатель, затем выбери тип графика.
2. Проверь доступность Matplotlib и SciencePlots; недостающие зависимости
   объяви в проекте или окружении генератора согласно выбранному маршруту.
3. Импортируй `scienceplots`, чтобы зарегистрировать стили Matplotlib. Применяй
   их через `plt.style.context(...)`: контекст ограничивает стиль одной фигурой
   и сохраняет соседние графики проекта.
4. Начни со стиля `science`. Добавь стиль поверхности или издания справа от
   него: `ieee`, `nature` либо `notebook`. Когда среда исполнения не содержит
   LaTeX, последним добавь `no-latex`.
5. Добавь один цветовой цикл для различимых рядов. `bright` и `high-contrast`
   дают палитры, рассчитанные на различение цветов; стиль `ieee` различает ряды
   также типом линии и поддерживает чёрно-белую печать.
6. Сохрани фигуру из её объекта через `fig.savefig(..., format="svg")` и закрой
   её через `plt.close(fig)`. Исходный код остаётся редактируемым владельцем, а
   SVG становится переносимым результатом.
7. Добавь к корню SVG доступные `<title>` и `<desc>` через
   `scripts/add_svg_accessibility.py`. Название называет фигуру, описание
   раскрывает показанные величины, сравнение и главный видимый результат.
8. Проверь SVG через `scripts/render_svg.py`, затем рассмотри целый график,
   уменьшенный размер публикации и полный масштаб. В целевом размере должны
   читаться подписи, единицы, различия рядов и интервалы неопределённости.

## Базовая форма кода

```python
from __future__ import annotations

from pathlib import Path

import matplotlib.pyplot as plt
import scienceplots


def render_measurements(
    x: list[float],
    y: list[float],
    y_error: list[float],
    output: Path,
) -> None:
    styles = ["science", "no-latex", "bright"]

    with plt.style.context(styles):
        fig, ax = plt.subplots()
        ax.errorbar(x, y, yerr=y_error, marker="o", label="Измерение")
        ax.set(xlabel="Время, с", ylabel="Амплитуда, В")
        ax.legend()
        fig.savefig(output, format="svg")
        plt.close(fig)
```

После создания графика добавь смысловое описание и проверь настоящий рендер:

```bash
SKILL_DIR="${CODEX_HOME:-$HOME/.codex}/skills/visual-explainer"
python3 "$SKILL_DIR/scripts/add_svg_accessibility.py" plot.svg \
  --title "Амплитуда во времени" \
  --description "Четыре измерения амплитуды с вертикальными интервалами погрешности. Наибольшее значение наблюдается при трёх секундах."
python3 "$SKILL_DIR/scripts/render_svg.py" plot.svg --output plot.png
```

Список стилей читается слева направо: каждый следующий стиль уточняет уже
заданные параметры. Для одной колонки IEEE используй
`["science", "ieee", "no-latex"]`; для статьи Nature —
`["science", "nature", "no-latex"]`; для тетради —
`["science", "notebook"]`.

## Проверяемый итог

Готовый график оставляет данные и код, из которых он воспроизводится, созданный
ими SVG с доступными названием и описанием и просмотренный рендер целевой
поверхности. Подпись каждой оси называет величину и единицу, легенда раскрывает
ряды, а показанная неопределённость имеет явного владельца в данных или
вычислении.

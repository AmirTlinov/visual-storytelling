# Раскадровки и действия

Для каждого шага запиши: исходные объекты → видимое действие → результат → короткая реплика.
При увеличении детали сохрани общую картину или вернись к ней после разбора.
Общие правила локальных подписей и единой модели — в [навыке](../SKILL.md#перенести-в-свою-тему).

## Пиксели → отклик нейрона

Один узел с заданными весами; числа подобраны для показа операции.

| Кадр | Объекты и действие | Реплика |
| --- | --- | --- |
| Вход | Увеличь два соседних пикселя. Шкала яркости: 0 — чёрный, 1 — белый. Значения 0,8 и 0,3 запиши в две ячейки. | «Слева светлее. Запишем яркость числами». |
| Веса | Ячейки сохраняются. Копии значений становятся отрезками: вес +1 сохраняет первый, −1 разворачивает второй. Вклады +0,8 и −0,3. | «Яркость справа уменьшает общий результат». |
| Сумма | На общей шкале +0,8 и −0,3 дают 0,5; сдвиг −0,2 переносит итог в 0,3. Появляется запись 0,8 − 0,3 − 0,2 = 0,3. | «Вычтем из разницы ещё две десятых». |
| ReLU | Положительное 0,3 сохраняется. Поменяй пиксели местами: 0,3 − 0,8 − 0,2 = −0,7 → 0. Покажи вход и выход правила. | «Светлая сторона слева даёт отклик. Теперь переставим стороны». |

Изменение входа раскрывает назначение этих весов. Для слоя покажи разные
отклики на тот же вход и их дальнейшее сочетание. При полном соединении каждый
нейрон получает все значения предыдущего слоя; подробный расчёт раскрывает один узел.
Названия скрытых признаков вроде «глаз» связывай с наблюдаемым поведением модели.

| [Перенос разряда](../assets/binary-carry.png) | Для 3 + 1 сверху остаётся исходное 011. Две единицы в вычислении образуют двойку; затем две двойки — четвёрку. | 011 + 001 = 100 |

## Что сохраняет операция

| Операция | Достоверное действие на рисунке |
| --- | --- |
| Чтение | Подсвети адресованную ячейку и создай копию значения для вычисления. Содержимое исходной ячейки сохраняется. |
| Запись | Замени прежнее значение в указанной ячейке; покажи адрес результата. |
| Биты | В каждой позиции 0 или 1; покажи порядок разрядов. Ячейка с дробью 0,8 представляет число, которому нужны несколько битов. |
| Умножение | Масштабируй величину; отрицательный множитель меняет знак. Отрезки со шкалой подходят для дробей, группы предметов — для целых неотрицательных значений. |
| Сложение | Объедини вклады на общей шкале; противоположные знаки компенсируются. |
| Обучение | Покажи ответ, цель, ошибку и поправку параметра. Повтори тот же вход с новым параметром. Для backprop раскрой влияние параметра на ошибку. |

При показе одной поправки зафиксируй остальные параметры. Для общего шага
пересчитай все затронутые параметры согласованно. Обобщение покажи на отдельном
незнакомом примере. Значения прямого прохода и влияние на ошибку должны различаться.
Трассу программы изображай как передачу значений; физику устройства — через её носители и процессы.

## Проверить объяснение

- Посмотри ключевой переход без звука: видны исходное состояние, действие и итог.
- Измени один вход и выведи новый ответ тем же способом: переставь пиксели,
  добавь предмет или прочитай другую ячейку.
- Проверь числа, сохранение объектов и соответствие рисунка операции.
- При пропущенном преобразовании добавь сам шаг. Затем проверяй письмо и плеер.

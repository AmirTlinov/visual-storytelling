# Живые чернила

`InkFusion` направляет штрихи двух исходных форм прямо в результат. `Physics2D.fusion` добавляет упругую деформацию Rapier. Сопоставление, деление и соединение линий рассчитываются автоматически; сцене принадлежат тексты, положения и время.

```ts
import { InkFusion } from '@visual-storytelling/core';
import { Physics2D } from '@visual-storytelling/core/physics/2d';
import '@visual-storytelling/core/style.css';

await document.fonts.load('100px SketchPencil');
const ink = await Physics2D.fusion(stage, {
  width: 840,
  height: 300,
  duration: 4,
  softness: 5, // Гц; выше — жёстче
  frame: (time) => ({
    sources: [
      { x: -140, y: 0 },
      { x: 140, y: 0 },
    ],
    target: { x: 0, y: 0 },
    morph: time / 4, // 0 — исходные штрихи; 1 — результат
    tension: 36,
  }),
});
ink.setShapes(InkFusion.text('свет'), InkFusion.text('тень'), InkFusion.text('объём'));
// Из общего transport; воспроизведение и перемотка используют одни часы.
ink.render(1.2); // секунды
// При удалении сцены: ink.dispose().
```

Сначала из обоих источников выбираются совпадающие слова, оставшиеся чернила распределяются между новыми словами. Затем подбираются буквы и штрихи. Сохраняющиеся слова не получают дополнительных копий из другого предложения; при равенстве форм учитывается порядок источников, чтобы одинаковые петли не пересекались. Форма букв оформляется в фазе контакта, положение слов плавно меняется до конца перехода. GPU соединяет близкие поверхности локальными перемычками, сила которых уменьшается вместе со сборкой текста. Почерк `SketchPencil` использует исходные векторные штрихи шрифта.

`morph` задаёт прогресс геометрии; длительность и плавность задаёт общий таймлайн. Rapier рассчитывает сетки по девять частиц для входящих слов и фигур; смещения передаются всем штрихам. При соединении они переходят в общее поле деформации своего слова, поэтому совпавшие линии остаются вместе. Деформация ограничена высотой букв и плавно исчезает на концах перехода. Физический шаг — 1/120 с; маленькие массивы смещений сохраняются для точной обратной перемотки. `frame(time)` должен возвращать одинаковые позы для одинакового времени; после изменения траектории вызови `setShapes` для сброса истории. Контактные перемычки принадлежат GPU-поверхности, столкновения управляющих сеток отключены, чтобы формы могли сливаться.

Во время морфа рендерер подавляет слишком мелкие штрихи по их размеру после деформации: порог учитывает толщину чернил и экранный масштаб. Видимость меняется плавно; исходный и конечный текст, включая пунктуацию и диакритику, сохраняется полностью.

Для сцены без упругости остаётся `InkFusion.mount(stage, options)` с `render({ sources, target, morph, tension })`; WASM ей не требуется. Оба варианта используют одно сопоставление и один рендерер.

`InkFusion.text(value, { size, maxWidth, lineHeight, align, font })` переносит слова по ширине и сохраняет явные переносы, включая пустые строки. Размер шрифта остаётся заданным. Для абзацев используй `align: 'left'`; высота готового блока доступна в `shape.bounds.height`. После изменения контейнера пересоздай текст с новой `maxWidth` и вызови `ink.setSize(width, height)`. Пример содержит слова, предложения, абзацы и многострочные поля для собственного текста.

`InkFusion.shape(width, height, paint)` принимает маску Canvas 2D: путь, изображение или фигуру. Для неё строится приближённая осевая геометрия с локальной толщиной; линии сопоставляются по положению, длине и очертаниям. Размеры, координаты и `tension` заданы в единицах сцены; поза поддерживает `scale` и `rotation` в радианах. `tension: 0` отключает контактные перемычки. Контейнеру нужна высота; рендереру — WebGL 2. Своего таймера у поверхности нет.

```sh
npm run build
npm run preview
# /ink-fusion/index.html
node tools/scene.mjs pack site/ink-fusion --out artifacts/ink-fusion.html
node tools/scene.mjs new /absolute/output/ink-fusion --example ink-fusion
```

Обычная сборка включает Rapier и работает офлайн. Для компактного показа в чате собери сцену с `visual-story build . --cdn`, затем `visual-story pack dist --inline --out story.html`: модуль Rapier загружается с jsDelivr по закреплённой в пакете версии. Сам пример и алгоритм остаются теми же.

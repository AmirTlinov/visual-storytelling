# Живые чернила

`InkMorph` принимает исходный и конечный текст, размещает его, сохраняет читаемость и добавляет упругость Rapier. Время приходит из общего рассказа.

```js
import { InkMorph } from '@visual-storytelling/core';
import '@visual-storytelling/core/style.css';

const ink = await InkMorph.mount(
  stage,
  {
    sources: ['Свет', 'Тень'],
    targets: ['Объём'],
  },
  { color: 'var(--ve-blue)' },
);
ink.render(frame.progress('meaning')); // 0…1, в любую сторону
// Новая глава: ink.setOperation({ sources, targets }).
// Удаление сцены: ink.dispose().
```

Предложения и абзацы передавай целиком: компонент учитывает переносы, ширину контейнера и высоту блока. Вместо строки можно передать маску `InkFusion.shape`. [Пример с телами и текстом](../written-morph/scene.js) использует этот же API.

## Устройство и собственные траектории

`InkFusion` владеет штрихами, сопоставлением и GPU-полем; `Physics2D.fusion` связывает эти же штрихи с Rapier. Их кадр `{ sources: poses, targets: poses, morph, tension }` нужен для собственной предметной траектории. В обычном рассказе её задаёт `InkMorph`.

Сначала из всех источников выбираются совпадающие слова, оставшиеся чернила распределяются между новыми словами. Затем подбираются буквы и штрихи. Сохраняющиеся слова не получают дополнительных копий из другого предложения; при равенстве форм учитывается порядок источников, чтобы одинаковые петли не пересекались. Форма букв оформляется в фазе контакта, положение слов плавно меняется до конца перехода. GPU соединяет близкие поверхности локальными перемычками, сила которых уменьшается вместе со сборкой текста. Почерк `SketchPencil` использует исходные векторные штрихи шрифта.

`morph` задаёт прогресс геометрии; длительность и плавность задаёт общий таймлайн. Rapier рассчитывает сетки по девять частиц для входящих слов и фигур; смещения передаются всем штрихам. При соединении они переходят в общее поле деформации своего слова, поэтому совпавшие линии остаются вместе. Деформация ограничена высотой букв и плавно исчезает на концах перехода. Физический шаг — 1/120 с; маленькие массивы смещений сохраняются для точной обратной перемотки. `frame(time)` должен возвращать одинаковые позы для одинакового времени; после изменения траектории вызови `setShapes` для сброса истории. Контактные перемычки принадлежат GPU-поверхности, столкновения управляющих сеток отключены, чтобы формы могли сливаться.

Во время морфа рендерер подавляет слишком мелкие штрихи по их размеру после деформации: порог учитывает толщину чернил и экранный масштаб. Видимость меняется плавно; исходный и конечный текст, включая пунктуацию и диакритику, сохраняется полностью.

Для сцены без упругости остаётся `InkFusion.mount(stage, options)` с `render({ sources, targets, morph, tension })`; WASM ей не требуется. Оба варианта используют одно сопоставление и один рендерер.

`InkFusion.text(value, { size, maxWidth, lineHeight, align, font })` переносит слова по ширине и сохраняет явные переносы, включая пустые строки. Размер шрифта остаётся заданным. На нижнем уровне для абзацев используй `align: 'left'`; высота готового блока доступна в `shape.bounds.height`. После изменения контейнера пересоздай текст с новой `maxWidth` и вызови `ink.setSize(width, height)`. Пример содержит слова, предложения, абзацы и многострочные поля для собственного текста.

`InkFusion.shape(width, height, paint)` принимает маску Canvas 2D: путь, изображение или фигуру. Для неё строится приближённая осевая геометрия с локальной толщиной; линии сопоставляются по положению, длине и очертаниям. Размеры, координаты и `tension` заданы в единицах сцены; поза поддерживает `scale` и `rotation` в радианах. `tension: 0` отключает контактные перемычки. Контейнеру нужна высота; рендереру — WebGL 2. Своего таймера у поверхности нет.

`setShapes(sources, targets)` принимает непустые массивы: 1→1, 1→несколько, несколько→1 и несколько→несколько. Кадр содержит обязательные `sources` и `targets` с тем же числом поз. Порядок массивов задаёт порядок одинаковых слов. Например, `[InkFusion.text('свет и тень')]` → `[InkFusion.text('свет'), InkFusion.text('тень')]` разделяет фразу; положение каждого результата задаётся отдельно.

`geometry` содержит заимствованные буферы последнего кадра, `bounds`, `distance(x,y)`, `tension` и `revision`. Один сегмент записан как `[ax, ay, bx, by, radiusA, radiusB]`; буферы действуют до следующего кадра. `onChange` сообщает обновление геометрии, `onDispose` освобождение поверхности. `Physics2D.fusion` публикует тот же интерфейс после упругой деформации.

Для столкновений с окружающими телами подключи `Physics2D.morph(world, ink, { id: 'ink-obstacle', scale: 100, cellSize: 1, at: [0,0] })`. Масштаб задан в единицах рисунка на мировую единицу; `cellSize` — размер ячейки коллайдера в рисунке. Коллайдер семплирует то же поле штрихов и контактных перемычек и обновляется по `revision`. Погрешность ограничена размером ячейки; мелкие невидимые фрагменты не становятся препятствиями. Привязка создаёт фиксированное препятствие, время и внешние тела принадлежат переданному Rapier world. `rigid` и `collider` возвращают актуальные native handles после восстановления world. Смена формы будит тела; после восстановления world привязка повторно применяет текущую видимую геометрию.

```sh
npm run build
npm run preview
# /ink-fusion/index.html
node tools/scene.mjs pack site/ink-fusion --out artifacts/ink-fusion.html
node tools/scene.mjs new /absolute/output/ink-fusion --example ink-fusion
```

Обычная сборка включает Rapier и работает офлайн. Для компактного показа в чате собери сцену с `visual-story build . --cdn`, затем `visual-story pack dist --inline --out story.html`: модуль Rapier загружается с jsDelivr по закреплённой в пакете версии. Сам пример и алгоритм остаются теми же.

# Как GPT выбирает следующее слово

Один интерактивный рассказ: фраза → токен и позиция → блоки → внимание →
вычисление → residual stream → MLP → собственный прогноз → следующий токен.
Блоки и слова открывают подробности. Внутри блока можно выбрать схему,
алгебру с MathMorph, геометрическую проекцию или поток аппаратных операций.
Все представления читают один forward pass; плеер, история и состояние общие.
На узком кадре «Детали» раскрывают соседние уровни: обе головы и оба блока,
LayerNorm, Q/K/V, маску и объединение голов. Слово в результате открывает
его собственный logit: итоговый нормализованный вектор · embedding этого слова.
Сумма произведений проходит через MathMorph, softmax возвращает её в распределение.

## Что действительно вычисляется

`checkpoint.json` содержит 1960 обученных параметров, весь искусственный корпус
из 18 русских фраз и контрольные результаты PyTorch. Модель — небольшой causal
decoder в стиле GPT-2: два pre-LayerNorm блока, две головы по четыре координаты,
residual width 8, MLP 8 → 32 → 8 с tanh-GELU, обученные позиции и общая матрица
embedding для входа и выхода. Контекст вмещает восемь токенов, включая начало.
Веса обучены с нуля; браузер выполняет вычисления локально без сервиса инференса.

Учебный словарь разделён по словам, знакам препинания и токенам начала/конца.
Это упрощение по отношению к BPE. Фразы из корпуса позволяют увидеть зависимость
продолжения от контекста; они не измеряют общую языковую способность.
Эта модель не воспроизводит закрытые веса или устройство современных моделей OpenAI.

Строки матриц — токены, столбцы — координаты: `XW + b`. Причинная маска
даёт будущим токенам ровно нулевой вес. Нормализация идёт по координатам одного
токена, с population variance и ε = 10⁻⁵. Attention показывает веса смешивания V;
один вес сам по себе не объясняет полное влияние токена на итоговое слово.
Отключение головы является явным вмешательством в forward pass.

Геометрия показывает указанную двумерную проекцию, а численный результат
использует все координаты. Аппаратный ракурс показывает регистры, умножение и
накопление выбранных чисел в binary64; это схема потока данных, без симуляции
транзисторов или конкретного GPU. Выбор выходной координаты MLP и выбор одного
из 32 скрытых нейронов хранятся отдельно.

## Где менять объяснение

| Файл              | Ответственность                                                      |
| ----------------- | -------------------------------------------------------------------- |
| `model.js`        | Модель, входы, trace, маска, прогноз и вмешательство                 |
| `checkpoint.json` | Обученные веса, корпус, параметры обучения, контрольные числа        |
| `scene.js`        | Путь рассказа, выбор предмета и ракурса, предметная композиция       |
| `computation.js`  | Trace → TensorData → MathMorph → тот же результат в модели           |
| `drawing.js`      | Использование публичных пера, письма, контролов и раскладки подписей |

Для другой темы создайте нейтральный проект через `story_create` без `example`.
Копирование этого рассказа — явное `example: "gpt-model"`. Общие часы, кадр,
масштаб, управление, материалы и арифметические превращения принадлежат библиотеке.

`Story` останавливает воспроизведение перед прогнозом. Выбор слова ещё не раскрывает
ответ; проверка показывает реальные вероятности, включая ошибочный вариант.
Явная перемотка и выпуск могут пройти к любому моменту. Числа округляются только
в надписях; инспектор и расчёт сохраняют исходную точность.
Исходный вектор, позиционная добавка и сумма раскрываются последовательно;
затем две ветви блока дописывают значения в residual stream. Прогресс пера и
письма вычисляется из общего `frame.time`, поэтому обратная перемотка точна.
При reduced motion сохраняются те же смысловые шаги без промежуточного движения.

## Проверяемость

`tools/train-teaching-gpt.py` воспроизводит обучение на CPU с seed 1729 и PyTorch,
закреплённым в заголовке скрипта. Полученный файл фиксирует версию, корпус, его
SHA-256, функцию потерь и все параметры. Node-проверка сравнивает каждую позицию
девяти фраз с независимым PyTorch forward pass. Отдельно проверяются causal mask,
residual, нормализация, GELU, отключение головы и происхождение чисел MathMorph.
Браузерные проверки покрывают прогноз, ракурсы, перемотку, размеры и доступность.

Архитектурные источники: [реализация GPT-2](https://github.com/openai/gpt-2/blob/master/src/model.py)
и [Attention Is All You Need](https://arxiv.org/abs/1706.03762).

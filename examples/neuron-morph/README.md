# Как нейрон собирает сигнал

`MathMorph.dot([2, -1, 0], [-0.5, 3, 2])` связывает пары входов и весов, произведения `[-1, -3, 0]` и итог `-4`. Ноль остаётся видимой ячейкой, происхождение произведений хранится в плане.

Оболочка даёт редактирование входов/весов, ход вычисления, перемотку, исследование и возврат к рассказу. `MathMorph2D` и `MathMorph3D` получают одну операцию и `render(frame, cues)`; движок задаёт переход, читаемую раскладку и reduced motion.

```sh
node tools/scene.mjs new /absolute/output/neuron --example neuron-morph --no-audio
cd /absolute/output/neuron
npm install
npm run dev
npm run pack
```

Рассказ тихий, 24 секунды. Входы и веса допускают числа от −6 до 6 с шагом 0.5. Изменение поля заменяет модель текущего кадра; «Рассказ» восстанавливает исходный пример.

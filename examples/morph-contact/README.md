# Форма становится опорой

`MathMorph.divide(6, 2)` управляет одной поверхностью и её разрезанием. `Physics3D.morph` передаёт текущее поле этой поверхности в Rapier; шар опирается на неё и падает после раскрытия щели. У шара нет сценарной траектории.

`PhysicsPlayer` владеет временем, `world.beforeStep` вычисляет кадр операции, общий Three.js binding сохраняет захват тела. Повтор восстанавливает физический snapshot и начальный кадр операции. [Контракт морфинга](../../docs/morphing.md).

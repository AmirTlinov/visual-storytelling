# Градиентный спуск по узкой долине

Независимый агент построил этот рассказ по обычному заданию, используя навык,
документацию и публичный пакет. Исходники движка при авторстве не открывались.
Первый работающий фрагмент появился за 6 минут 45 секунд.

- `valley.js` — квадратичная функция, поворот и дискретный шаг.
- `models.js` — связанные 3D-поверхность, линии уровня, траектории и значения через `MathMorph.model`.
- `scene.js` — три главы, параметры и озвучка через `MorphStory`.
- `narration.json` — шесть реплик с действиями, 137,68 секунды.

Экранных координат, собственного рендерера и ручных часов в сцене нет.
Высота изображена в масштабе `0.16 f`; сверху сохранён одинаковый масштаб осей.
Шаги α и β независимы, чтобы сравнивать обычный метод и предобусловливание.

Проверены перемотка в обе стороны, вращение во время рассказа, быстрые изменения
параметров, нулевой градиент, 375 px, тёмная тема, reduced motion и автономный HTML.
Численная проверка направления конечными разностями: ошибка `1.04e−10`.

Пробник выявил общие дефекты дискретизации, глубины линий и переноса текста;
исправления находятся в библиотеке. В повторённом браузерном сценарии смены α
обработка события сократилась со 146 до 43 мс, Event Timing — со 168 до 64 мс.
Это локальный замер под CDP-захватом на 375 px.

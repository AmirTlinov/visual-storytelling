# Математические превращения

Сложение, деление, умножение, степень и непрерывная экспонента в одном тихом рассказе. Плоскость и вращаемый объём принимают одну операцию `MathMorph` и один прогресс общего `SceneShell`.

В `scene.js` находятся только выбор операции, входные числа, текст вопроса и метки рассказа. Геометрия, пропорции, арифметика и стадии перехода принадлежат `MathMorph2D` / `MathMorph3D`; у примера нет собственного морфинга или проигрывателя.

Меняй главу для рассказа или включи «Исследовать» для своих чисел. «Объём / Плоскость» сохраняет время; ручной поворот остаётся доступен при воспроизведении.

Точные доступные параметры: `npx visual-story api MathMorph MathMorph2D MathMorph3D`.

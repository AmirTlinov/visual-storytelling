# Что делает действие?

Четыре действия на предметах: собрать шарики, отдать монеты, повторить группу клеток, раздать половинки пирогов. Сложение и умножение дают одинаковое число разными путями; вычитание сохраняет отданные монеты у получателя, деление сохраняет общую площадь пирогов.

`lesson.js` хранит смысл и метки, `diagrams.js` — предметные размещения, `drawing.js` — изображения. Общие `surface`, `regroup`, `lettering` и `SceneShell` владеют рисунком, интерполяцией, письмом и временем. Предметы сохраняют SVG-идентичность при перемотке.

Выберите действие и воспроизведите его; итог появляется после движения. Тот же момент доступен через `root.scene.seek(time)`. Пример показывает положительные количества; половинка означает половину исходного пирога.

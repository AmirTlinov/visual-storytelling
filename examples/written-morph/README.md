# Форма несёт смысл

Новый рассказ через публичные `Morph`, `Morph3D`, `Morph2D` и `InkMorph`: единица на кубике и шаре, 1 + 2 → 3, Свет + Тень → Объём, разделение целого, слова и абзацы.

Сцена задаёт объекты, операции и метки времени. Сближение, форма, контакт, надписи, упругость текста и адаптация к размеру экрана принадлежат библиотеке. Главы, произвольная перемотка, ручной ракурс и переключение 2D/3D используют общую оболочку. [API](../../docs/morphing.md).

```sh
npm run build
node tools/scene.mjs preview site/written-morph --port 8822
node tools/scene.mjs new /absolute/output/story --example written-morph
```

# Физические материалы

Два примера одной модели поведения: [SVG](index.ts) и [3D](three.ts). Твёрдое тело сохраняет форму, упругое отскакивает, мягкое сминается на опоре. Перетаскивайте тела, используйте паузу, шаг и «Сначала»; SVG также принимает стрелки клавиатуры.

Общий код, материалы, захват и время принадлежат `src/physics/`. [Авторский API](../../docs/physics.md) описывает единицы, привязку существующих Mesh, связи и повтор состояния.

После `npm run build`: `site/physical-objects/index.html` и `site/physical-objects/three.html`.

# Исследование устройства

Новое устройство начинается с нейтрального каркаса; предметная модель принадлежит сцене.
Команды ниже запускаются из каталога навыка:

```sh
node ../../tools/scene.mjs new /absolute/output/my-device
cd /absolute/output/my-device
npm install
npm run build
npm run dev
```

## Владельцы

- `ExplorerSurface` создаёт SVG, доступные HTML-цели, возврат и путь.
- `SvgCamera` размещает рисунок и цели, приближает выбранную деталь и отменяет устаревший переход.
- `SvgHighlight` получает контур из группы `data-part`; `SvgGestures` различает нажатие, перенос и pinch.
- `ScenePath` хранит путь. Сцена задаёт идентичность объекта; перекрёстная ссылка возвращает к существующему предку.
- `SimulationPlayer` подключает изменяемую модель к общему плееру: пуск, пауза, следующий шаг. Предметная модель владеет вычислением и начальным состоянием.
- `widgetState` переносит `scene.capture()` в `privateContent` и восстанавливает его через `scene.restore()`. Вложенная модель подключается как `runtime.subject`; валидация её версии и значений остаётся у сцены. [Контракт checkpoint](../../../docs/authoring.md) общий для Codex, локальной страницы и текущего экспорта.

Сцена возвращает `{body, box, hits}`; цель — `{key, label, node, box}`. `body` содержит SVG-группу `data-part="key"` для каждого открываемого объекта. Координаты целей и рисунка совпадают. Выделение повторяет контур предмета; текст остаётся вне силуэта.

## Проверить

Открой деталь и вернись во время приближения; проверь повторные нажатия, touch/pinch, клавиатурный фокус, узкую ширину и обе темы. Сохрани изменённые данные на глубоком уровне, перезагрузи и продолжи. Пауза и `dispose()` останавливают время и освобождают обработчики. Экспорт HTML сохраняет исследование; SVG/PNG фиксирует текущий рисунок.

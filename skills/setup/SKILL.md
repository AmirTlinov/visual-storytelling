# Первый запуск Visual Storytelling

Вызови `story_help`, затем `story_open` с `example: "graph-lab"`. Успешное открытие этого интерактивного графика завершает проверку. Голос и дополнительные загрузки для первого просмотра не нужны. Для дальнейших запросов выбирай основу по задаче из общего каталога; `story_open` без входа возвращает доступные основы.

Если запуск сообщает об отсутствующем launcher, установи комплект с помощью поставляемого Node: из корня этого плагина выполни `./runtime/node ./plugin/install.mjs --skip-registration`. Корень находится на два уровня выше этого `SKILL.md`. Установщик копирует выпуск в постоянную папку `~/Library/Application Support/Visual Storytelling/installation`; исходная папка и кэш Codex после этого не участвуют в запуске. Переподключи плагин и повтори `story_help` и `story_open`.

При `RUNTIME_VERSION_CONFLICT` дай завершиться текущей подготовке, закрой карточки Visual Storytelling и переподключи плагин. Повтори открытие после переподключения. Установщик сохраняет предыдущий выпуск для активных процессов; не удаляй его и не завершай процессы принудительно.

После открытия коротко покажи, что пример можно исследовать руками и обсуждать в чате. Новые проекты сохраняются в `~/Library/Application Support/Visual Storytelling/projects`. Если пользователь выбрал другую папку, применяй её через `story_preferences`; существующие проекты сохраняют свои закреплённые версии библиотеки.

При ошибке сохрани её точный код и сообщи один следующий шаг. Подробности установки — в [INSTALL.md](../../plugin/INSTALL.md).

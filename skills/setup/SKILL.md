# Первый запуск Visual Storytelling

Вызови `story_help`, затем `story_open` с `example: "gpt-model"`. Эталон «Как GPT выбирает следующее слово» показывает действующий рисунок, взаимодействие и рассказ. Успешное открытие завершает проверку; голос и дополнительные загрузки для первого просмотра не нужны.

Для нового объяснения следуй маршруту `story_help → story_create → story_edit → story_review → story_open → story_produce`. `story_create` без `example` создаёт нейтральный редактируемый проект без карточки и сеанса; сначала наполни и проверь его. Передай `example: "gpt-model"`, только когда нужна копия этого объяснения. `story_open(projectId)` показывает подготовленный результат.

Если запуск сообщает об отсутствующем launcher, установи комплект с помощью поставляемого Node: из корня этого плагина выполни `./runtime/node ./plugin/install.mjs --skip-registration`. Корень находится на два уровня выше этого `SKILL.md`. Установщик копирует выпуск в `installation` внутри папки приложения: `~/Library/Application Support/Visual Storytelling` на Mac, `${XDG_DATA_HOME:-$HOME/.local/share}/visual-storytelling` на Linux. Исходная папка и кэш Codex после этого не участвуют в запуске. Переподключи плагин и повтори `story_help` и `story_open`.

При `RUNTIME_UPDATE_PENDING` дождись завершения текущего задания: прежний runtime сохранит сеансы и освободит владельца. При `RUNTIME_UPDATE_REQUIRED` переподключи плагин в текущем чате; другие чаты могут оставаться подключёнными. `RUNTIME_VERSION_CONFLICT` относится к legacy-runtime до 0.13.0: заверши подготовку и закрой его карточки. Если конфликт сохраняется, требуется однократное аккуратное завершение прежнего runtime с сохранением данных по [INSTALL.md](../../plugin/INSTALL.md); повторное переподключение само по себе его не освобождает. Не удаляй выпуски, используемые процессами, и не завершай процессы принудительно.

После открытия коротко покажи, что пример можно исследовать руками и обсуждать в чате. Новые проекты сохраняются в `~/Library/Application Support/Visual Storytelling/projects` на Mac и `${XDG_DATA_HOME:-$HOME/.local/share}/visual-storytelling/projects` на Linux. Установщик Linux сохраняет выпуски в `installation/releases` внутри папки приложения. Если пользователь выбрал другую папку, применяй её через `story_preferences`; существующие проекты сохраняют свои закреплённые версии библиотеки. На Linux Higgs/MLX и системный голос macOS недоступны; первый просмотр и тихий авторский путь работают без них. Для PNG/видео могут потребоваться системные библиотеки Chromium по инструкции установки.

При ошибке сохрани её точный код и сообщи один следующий шаг. Подробности установки — в [INSTALL.md](../../plugin/INSTALL.md).
